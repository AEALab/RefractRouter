# 自动路由真实数据准入

## 适用入口

本合同只适用于 RefractAgent 自动路由的 `auto-live` 入口。标准模型 Base URL
与规划路由的策略入口继续保持独立；DAG、工具与 DSH 会话信息不进入标准模型接口。
自动路由处理选模、规划是否值得执行、模型费用和审计；工具权限与执行仍由宿主控制。

## 数据模式

`dshModelPool.security.dataMode` 支持 `synthetic`、`desensitized` 和 `live`。
三者均须通过每任务零调用预检、模型容量、预算及宿主工具门禁。

选择 `live` 时，本次任务的模型清单先收窄到明确声明为 `local` 或
`trusted-cloud` 的路线，再进行规划、候选比较、执行与评审。可信云仍须具备有效的
信任策略，明确允许敏感数据；普通 `external-cloud` 不参与本次任务，即使任务文本
没有命中邮箱、路径或密钥等确定性规则。`simulated-local` 不因名称中的「本地」
取得真实数据资格。模型目录和用户既有绑定不被改写，切回其他模式仍可使用原路线。

这个门禁覆盖原始用户请求、规划器、工具结果交接和最终评审。
没有合格的规划、执行或评审模型时，预检直接报告缺项；预算不足也不会暗中
改用未授权路线。`desensitized` 要求调用方确实提供已脱敏材料，不能把选中该模式
视为自动完成脱敏。真实数据模式不扩大宿主工具权限，也不自动授权其他云端 Judge。

## 检查与回滚

设置页展示数据模式及每条模型的部署域与信任策略。切换模式后，新任务按新配置
重新预检；运行中的任务继续使用已经冻结的请求与授权摘要。故障时可在原设置页
关闭自动路由真实执行或恢复先前数据模式；配置、凭证、会话和原始账本不随回滚删除。

本次有限接线结果见[验收记录](../reports/automatic-live-20261005/README.md)。
合成任务在 `live` 准入下通过，只证明接线与数据域过滤正确，不能推断任意真实业务
任务质量，也不能把直接执行候选称为已运行多节点 DAG。
