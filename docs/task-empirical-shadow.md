# 整任务经验费用与影子选择

关联 [#205](https://github.com/AEALab/RefractRouter/issues/205)、
[总计划 W04](https://github.com/AEALab/RefractRouter/issues/201)。本包正在开发，尚未提交PR或
完成全量及独立审查；以下首批组件通过不代表模型资格或影子选路已经验收。

`task_cost_observation.observe` 从 #203 的 `task-result-v1` 原账本投影提取整任务逐调用费用，
包含分类、执行、返工、审核与丢弃候选。逐调用金额须与原总账一致，遗漏或重复不能当作
更低成本。未知状态保留最大已占用/预留数值，并标记费用未完整；不会释放或改写账本。

金额按币种和计费模式保留。订阅参考估值与计量预算分账，不能当成同一现金支出；
已知 token 计价也不等于 provider 实际扣款。实际扣款继续标记为本视图未建立，
不把原有研究的未知 AFP/CNY 预留当作零。缓存用量不完整时不假定已命中缓存。
范围限于 Router 管理的调用，外层 Agent 与子 Agent 未覆盖费用保持原状态。

费用观测本身始终不证明质量。后续仍须完成：独立验收与实际候选/模型版本绑定、
同任务类型/路线/缓存条件分层、样本数及质量不确定范围、完整费用预测和预测误差、
价格过期/版本漂移拒判，以及版本化配置下的运行时影子接线。缺少证据时保留未知，
不根据单个 Choice 概率推导全池资格。实际执行仍保持现有首次调用成本合同，
任务内模型固定，硬预算继续由原预算账本执行。
