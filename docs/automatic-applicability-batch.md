# 自动路由适用范围的有限对照

关联 Issue #113，基于已合并 PR #189 的工具证据与准入基线。本轮适用于独立自动路由研究入口，
标准模型 API 和 Codex 接口仍不进入 DAG。

## 冻结任务

六个公开项目源码审查任务各比较一次 Direct 与显式 DAG：

| 类型 | 任务 | 交付 |
| --- | --- | --- |
| 简单单模块 | 费用面板、工具验收 | 核对表、修正提案与验证条件 |
| 顺序依赖 | 取消恢复、跨语言请求包络 | 从源码推导状态，再提出修复与回归 |
| 独立分支 | 费用与工具审查、三模块发布审查 | 分支风险和提案，再汇总上线建议 |

公开协议在 `data/research/automatic-applicability-v3.json`。材料按源码 SHA-256 和选取范围
冻结，补齐函数依赖的常量和事件字段。参考答案仅供实验检查，不发送给执行模型。

事实字段精确核对、中文说明完整性和本项目最终模型评审分别报告。字段存在或 Judge 高分
不能替代独立语义复核。这些是基于真实项目代码的封闭材料审查，含模拟故障数据，
不是生产用户任务；部分来源共享，不能宣称来源隔离留出或普遍收益。

## 调用合同

- 模型目录、角色、价格和信任读取原 DSH 快照；Python 执行候选与账本逻辑。
- Direct 实验副本使用 `dagMode=never`，DAG 对照使用 `force`。
  强制单节点须单独报告，不能称为多节点或自动入口选中了 DAG。
- 两路线使用相同候选池、质量门槛、提供方默认推理档位和最终评审。
- 最多 60 次调用；Direct 每任务最多 2 次，DAG 最多 8 次。
- 输出上限 8192，输入采用保守序列化包络 32768；不声称它是精确 tokenizer 数。
- 规划最多 90 秒，仍受整任务 300 秒及剩余期限限制；超容量明确停止，不截断材料。
- 零 HTTP 重试、零节点回退、零规划修复、无委派、同步桥单并发。
- 新 Jev 调用为零；固定两路线对照不证明 Jev 自主选路准确率。
- 普通已结算任务失败保留后继续；认证、未知用量、证据或授权异常停止整批。
  不能自动重发可能已计费的请求。

## 费用与隐私

公开参考估值、现金费用和未知预留分别记录；订阅单次现金保持未归属，
不把公开参考价称为提供方实际扣款，也不把订阅视为零总成本。
互斥候选只用单次最坏价格形成授权包络，不累加所有模型费用。
预算保护和结算复用 Python 现有原子账本。

执行前通过 `--authorized-cash-cny` 指定实际已获授权的额度，通过
`--extra-history-protection-cny` 保护独立历史现金；默认入口仅预检。
预检冻结模型、核心及插件源码、实际桥接构建、宿主适配器摘要、材料、顺序、费用包络
及去重历史，实跑必须匹配摘要和全新输出目录。材料始终从冻结的来源提交验证，
运行实现的修复不替换题目中的历史源码片段。
单任务现金限制继续读取用户配置，实验副本不写回日常设置。

真实产物含用户配置和本机路径，应保存于 `.refractagent/private-audit/` 等忽略目录。
公开仓库只提交代码、公开任务与经授权的脱敏摘要，原账本和配置快照保留在本机核对。
历史核对同时扫描工作树和已部署项目的私有证据目录，复制记录按派发身份去重，
不能因隐私存储位置变化而漏算已结算现金或未知用量预留。

## 规划限制修复

原有有界模式会把规划输出固定为 2048；请求构建又可能先删除显式期限，再恢复有界标记，
导致期限退回默认值。修复后保留显式容量和期限，预算与真实派发使用相同包络。
旧有界模式未填写时仍采用旧默认；旧 task API 的 2048／30000 上限保持原合同。
新增内部 `boundedPlannerLimits` 仅开放显式有界路径，无界与有界不能同时开启。

测试覆盖实际调用的输出上限、客户端期限和剩余任务期限；适配器经 `for_task_call`
传递期限，不向不接收该参数的 `complete` 传参。
