# #39、#40 关闭条件核对

核对日期：2026-09-09。依据 GitHub 当日开放的
[#39](https://github.com/AEALab/RefractRouter/issues/39) 和
[#40](https://github.com/AEALab/RefractRouter/issues/40) 原始验收要求。
本清单不变更 Issue 范围，也不以降低要求代替验证。

关闭取决于完成事前定义的实验并交付可复核证据，不要求正收益。
无改善、某些分层证据不足或可解释的失败都是允许的研究结论；
未执行的验收不能写成已经完成。

| 验收 | 当前证据 | 达成方式 |
| --- | --- | --- |
| 任务范围、样本量、材料独立性 | 有两个共享模板族的草案，不能支持广泛迁移 | 建立可追溯材料清单，审核来源、近重复及划分；限定外推范围并冻结样本量依据 |
| 运行器与失败记账 | 开发执行器及模拟故障验证已完成 | 补齐正式矩阵编排、异构交接及成本分类，再执行真实验证 |
| #39 固定 DAG 对称对照 | 仅有预定实验组 | 冻结节点 A/B 与同图单模型 A/B、质量与并发对照，采集真实交接及最终评分 |
| #40 自动规划端到端对照 | 仅有预定实验组与语义标准 | 冻结整任务 A/B 校准，执行人工、冷启动、计划复用和整任务对照，保留计划与真实时间线 |
| #40 人工抽检 | 只有规则，没有人工记录 | 按事前规则生成盲化复核包，由真实人员记录判断、理由及复核范围 |
| 统计与证据交付 | 统计单元测试通过，尚无真实研究结果 | 对共同配对及全计划分母复算，费用按阶段分列，合并代码并回填 #1、#22、#8 |

## 可以自动承担的工作

运行器、无网络测试、公开材料整理、来源与重复检查、协议冻结、零调用预算计算、
获授权后的真实模型执行、原始证据归档、统计复算、复核包和报告均可由编码代理执行。
任务材料不必全部来自用户，也不必全部来自线上真实团队任务；材料来源和外推范围须明确。
共享模板不自动否定参数抽样的独立性，但不能将两个模板族的结果外推为广泛任务迁移。

目前两个草案的留出材料已用于设计检查，后续修改生成器或评判标准时，
应将这些材料保留为开发资料，另建最终留出版本，不能反复对同一留出调试。

需要真实人员完成的是 #40 明确要求的人工复核；模型评审不能被登记为人工评审。
真实调用前还须对最终协议范围和费用上限取得授权，当前草案的约 50.9 万 AFP
是保守包络，不是实际消耗预测，更不是建议直接执行的预算。

## 本轮实际验证

执行 `uv run pytest tests/test_research_protocol.py tests/test_research_analysis.py -q`：
25 passed，耗时 0.30 秒，无真实模型调用。
读取最新 Issue 正文，确认两项仍为 OPEN，均明确不要求正收益。
检查研究实现：`live_execution_ready`、`independent_task_transfer_verified`
和 `benefit_verified` 当前均为固定 false；它们不是已实现的证据驱动验收判定。

该结果只证明现有离线检查通过，不能证明真实执行、材料迁移、规划质量或综合收益通过。
首个工程里程碑应为开发材料上的完整执行与故障模拟，而不是立即关闭 Issue 或执行整个付费包络。

## 后续真实验证进展

用户后续授权真实调用且免逐项预算确认。首批完成 42 次调用，12 条路线中 9 条交付通过；
发现完整验收条目没有传递给人工计划、直接回答和节点探测，导致不同路线的信息不一致。
修复后增加 6 次真实回归，两条 SQLite 路线均通过。两批共消耗 52.3174 AFP，
全部调用结算与原始证据审计通过。完整软件测试为 583 passed、5 subtests passed。

这些是先导及针对性回归证据，不是完整研究验收。正式新留出、对称 A/B、真实异构交接、
成本分类及人工复核仍未完成；9 份先导计划人工复核模板已生成，尚无人工填写结果。
