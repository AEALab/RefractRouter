# 规划路由日常使用指南

核对日期：2026-10-10；对应核心 0.16.33、插件 0.33.21。
规划路由在接入方原生 Agent 循环中选择模型与审核候选，不创建 DAG。
工具、权限、技能、上下文、委派和任务推进由宿主负责。

## 如何设置

在 DSH **设置 → 插件 → RefractAgent 规划路由** 中配置共用模型、预算、数据域，
再编辑策略自己的执行器与 Judge。正在编辑的策略不改变默认策略。
在对话模型菜单的 **路由模式** 中选择当前会话策略；底层推理等级从真实模型的支持值选择。
保存设置从下个任务生效，工具续接与进行中的追加指导沿用当前冻结状态。

新 v7 配置使用 CNY 参考估值与按量现金账本，不再用 AFP 计价；保留 Ark 订阅接口。
两列不相加，参考估值不等于订阅扣款。预算、期限和调用数的 0 表示不设相应 Router 上限，
仍受模型容量、提供方与技术上限约束。旧 AFP 配置显式迁移，历史金额不追改。

零调用检查只核对配置可派发，不评价 Judge 正确性或收益。运行后查看实际模型、判别、
接受／丢弃、费用、保护额度、待核对预留和等待时间。

## 六种策略

| 策略 | 行为 | 必要设置与边界 |
| --- | --- | --- |
| Static | Fixed 使用高效角色；Random 在两个执行角色加权随机一次 | Fixed 无需 Judge；当前 Random 不是任意多模型池 |
| Stage | 新可信工具证据决定临时接管、保持与恢复 | 默认规则无 Judge；规则＋Jev／Laya 保留实验 |
| Task | 任务开始从池中选主模型，任务内保持 | 多候选一次 Judge；单候选跳过；指定备援也须合格 |
| Composite | Task 选常用模型，Stage 后续临时接管 | 独立池、Task Judge 与接管模型；规则后续无额外 Judge |
| Advisor Gate | 最终首审、最多一次返工与复审 | 固定执行器、独立审核器；未审定停止，不交付候选 |
| Escalation | 检查起始候选，必要时一次接管并锁定 | 独立起始／接管／Judge；接管后不再审核 |

Stage／Composite 不从文字中的“失败”猜测工具退出状态。
DSH 原生事件可提供可信事实；Codex CLI 的可选证据适配另见
[客户端工具证据](client-tool-evidence.md)。纯 Base URL 可能只能记录回执，不能证明自然重复失败。

## Judge 的选择位置

- **LLM**：选择策略的 LLM 后端和对应 DSH 模型，使用该用途的结构化合同。
- **官方 Jev**：选择 Judge 类型“官方 Jev”，在独立渠道设置中核对 OpenRouter、
  `OPENROUTER_API_KEY` 凭证引用、数据域和信任策略；不在普通审核 LLM 下拉框寻找。
- **本地 Laya**：选择本地结构化 Judge，提前下载固定权重、加载并预热；当前质量实验标识保留。

新 Jev 配置默认 OpenRouter，旧配置不静默换渠道。Advisor／Escalation 默认按获选项概率门槛
判断，`confidence` 记录供观察；分动作 probability＋confidence 门槛为显式实验选项。
详见[Jev 接入](jev-planning-routing.md)。不能把概率、分数或低延迟解释为任务成功率。

## 费用与质量

Judge、丢弃、返工、接管与失败尝试计入总体模型开销。未派发保护额度释放；已派发未知用量
保留并停止，不自动重试。宿主其他工具及独立子 Agent 费用尚未进入主任务硬预算覆盖。

当前 DSH 是主要产品验证路径。Codex CLI 按标准协议、策略和证据适配分别验收；
Hermes 的历史内容保留，不作为本轮新增支持范围。媒体、P6 和开放任务收益另行验收。

详细策略说明见[在线文档](https://aealab.github.io/RefractRouter/strategies/)，
具体历史证据见[支持矩阵](planning-routing-support-matrix.md)。
