# 规划路由日常使用指南

规划路由在接入方原有 Agent 循环中选择模型，并在必要时审核候选回复。它负责受管模型调用的
准入、费用与轨迹；工具执行、权限、上下文和委派由 DSH 等接入方负责。当前最完整的产品
验收来自 DSH 的文本及原生工具任务。选用策略时先明确可接受的任务质量，再比较全部模型
调用费用，最后比较首字等待和完成时间。

## 如何设置

在 DSH「设置 → 插件 → RefractAgent 规划路由」中配置模型和预算。`AFP` 与 `CNY`
分别记账；`0` 表示该单位的单任务预算不设 Router 上限。选择「正在编辑的策略」可以查看
和修改任一策略，**不会改变「默认路由策略」**。保存后的参数从下个任务开始生效。
对话中可从模型菜单的「路由模式」为当前会话选择策略。

「零调用检查」的“配置可执行”表示模型、价格、预算、数据域和宿主能力等派发准入条件
已经满足。它不评价 Judge 是否判断正确，也不承诺该策略一定省钱。每次运行后在「路由轨迹」
核对实际模型、触发原因、Judge 原始结果、回复接受或丢弃，以及 AFP／CNY 分项费用。

## 六种策略怎么选

| 策略 | 适合的用法 | 模型调用与费用 | 使用前需知道 |
| --- | --- | --- | --- |
| Static | 固定一个模型作稳定基线；随机模式用于对照 | 每次执行只调用选中的模型 | 随机选择按冻结权重和种子，不保证质量或省钱 |
| Stage | 工具任务中依据可信执行证据临时换模 | 默认规则模式无 Judge 费用；只为选中执行模型计费 | 没有可信工具状态时维持高效模型；规则＋Jev／Laya 属实验 |
| Task | 任务开始从模型池选一个主执行模型，后续保持 | 多个合格候选时至多一次 Task Judge；再计执行费用 | 单一合格候选不调用 Judge；无法确定时只用指定备援。本地 Laya 尚未达到日常判别门槛 |
| Composite | Task 选常用模型，Stage 规则在困难时临时接管 | Task 至多一次 Judge；默认后续规则不增加 Judge 调用 | 接管模型须由用户指定；规则＋Judge 轨迹判别属实验 |
| Advisor Gate | 最终回复必须审核，允许一次返工并复审 | 执行、最多两次审核和一次返工执行均计费 | 未批准的最终回复不会交付；当前自然任务误放行率证据仍有限 |
| Escalation | 先由起始模型尝试，审核未交付候选，必要时接管 | 起始执行、Judge 和可能的接管分别计费；接管后不再审核 | 无法判断也会接管，可能增加费用与等待；需观察不必要接管 |

Stage 与 Composite 的规则换模只依据可信工具事件。普通 Base URL 文本工具结果若没有
可核验退出状态，会被标为无法分类，Router 不从正文的“失败”推断模型能力不足。DSH
原生工具事件可提供结构化证据；Codex CLI 与 Hermes 需要各自的可选证据适配才能覆盖
自然重复失败换模。纯对话或没有有效证据时，Stage 通常继续使用高效模型。

## Judge 的选择

- **轻量 LLM：**通过 DSH 已配置模型调用，产生独立费用。Task、Composite、Advisor 和
  Escalation 使用各自的判别合同，不能把一种用途的分数解释为另一种用途的准确率。
- **官方 Jev：**新配置默认通过 OpenRouter；旧配置保留原接入渠道。Task、Stage 协作、
  Composite 的 Task／Stage、Advisor 和 Escalation 均已接线，费用计入 CNY。
  Advisor／Escalation 默认按获选项概率门槛判断；同时检查 `confidence` 的分动作规则
  仍为显式实验选项。当前 DSH profile 的 Advisor／Escalation 使用 OpenRouter Jev。
- **本地 Laya-MLX：**不产生 API 费用，但会占用本机资源。已测固定 checkpoint 在
  Task、Stage、Advisor 和 Escalation 的对应题集中未达到日常质量要求；本机就绪只表示
  可以运行。当前 DSH profile 的 Task 仍使用该实验后端，选用 Task 时应先看路由轨迹
  和备援结果。

当前 profile 默认是规则 Stage；Composite 使用轻量 LLM Task Judge 与规则 Stage。
图片／影片完整路线、子 Agent 共享预算及开放任务收益证明分别保留为独立验收项。
六种策略的具体证据和客户端边界见[支持矩阵](planning-routing-support-matrix.md)。
