# node-as-tool 当日先导验证

## 目标与范围

回答：需要多个专业职责协助的候选任务中，按需调用专家，相对一次性回答和完整 DAG，
是否出现可核对的事实改进、总费用下降或耗时变化。暂不开发自动／规划模式选择器。

三条路线固定同一 `deepseek-v4-flash`，避免把不同模型的能力差误记成执行方式收益。
这是低风险开发先导，不能推断所有模型、真实业务或正式留出的表现。
任务在执行前按材料分析、约束核对与计算等职责选择，不按路线胜负挑题，
也不预设任务必须拆分。没有使用专家或没有拆图时照实记录。

## 冻结任务和交付

`data/node-tool-pilot-v1/tasks.json` 包含 3 个构造开发任务：

- 采购：报价版本、税、折扣、运费、保修、交期及证书资格同时约束。
- 发布：更新后的依赖、工时、两槽并发、发布窗口及尚未发生的批准。
- 流水与代码：事件去重、载荷冲突、退款余额、pending 与错误代码诊断。

所有路线只收到同一个 `execution_payload` 公共投影；参考答案、结构标签和审查记录不进入执行消息。
模型无文件、命令、网络检索或其他宿主工具；node-as-tool 仅开放文本专家工具。
引用参考位于独立 `references.json`，只供运行后事实检查。自动检查能发现关键字段错误，
不能证明正文语义或参考材料已由独立真人认可。

## 三路线

| 路线 | 执行与记账 |
|---|---|
| one-shot | 一个模型请求直接交付 |
| node-as-tool | DSH 原生主循环按需调用专家；最多 4 次主请求及 3 次专家请求，全部进入父账本 |
| DAG | 既有 Python 紧凑规划器和节点执行器；实时生成最多 4 节点，最多两节点并行；规划费用及等待计入 |

最终输出统一 `answer/findings`，容量均为 8192 output tokens；中间专家／DAG 节点为 2048。
公共最终输入上限为 65536 UTF-8 保守字节界限，不把这个研究限制伪装成提供方模型容量。
专家只显式接收所需文本，不宣称所有路线只有一个上下文或消除了交接损失。
不同执行方式还改变提示与上下文投影，比较的是整体执行方式，不作纯交接损失的因果归因。

## 公平性和费用冻结

先用 2 个预先定义的 one-shot 提示候选，3 题各重复 3 次，共 18 次调用。
按关键事实通过数、失败检查数、费用与稳定字典序选择基线提示；不使用后续三路线结果调参。
这个有界开发搜索不等于独立语义审查后的最优提示。三路线再各题重复 3 次，形成 27 个样本。
路线顺序预注册交错，重复不当作独立任务样本。

最大模型请求总数 135，包含全部主请求、专家与 DAG 规划。按官方常规系数 0.5 计算，
保守逐阶段包络之和为 285.000750 AFP，向上取整的整批上限为 **286 AFP**。
AFP 为 Ark Agent Plan 套餐用量，不是人民币实付；本批不调用额外付费 Judge。
来源：[官方 AFP 抵扣规则](https://www.volcengine.com/docs/82379/2516283?lang=zh)，核对日 2026-10-29。
只用 `/api/plan/v3`，底层重试、节点模型回退和规划修复均为 0。

付费仍须按 AGENTS.md 取得本批明确范围和预算授权。预检和演练不读取实际凭证值、不调用真实模型。
真实执行只通过 `CODEX_ARK_API_KEY` 引用取得凭证，不写入产物或命令行。
拒绝复用证据目录；冻结任务、核心、适配器和定价摘要改变时必须生成新协议。
每样本核对源码未变，且实际请求在派发前检查输入、输出、次数及费用包络。
费用已知的模型输出失败停止该任务下游并保留失败，继续独立样本；认证、未知用量、
账本或证据写入异常停止整批，保留预留，不自动重试。

## 当天交付与边界

交付原始模型输出、实际工具／DAG 轨迹、用量、费用、任务时间、逐任务事实检查、
翻转矩阵和完整／缺失配对数。单任务执行期限 10 分钟，全部批次有界，适合当天先导。
模型／规划执行计时与进程冷启动外层耗时分别记录，避免把宿主启动误当作模型速度。

没有独立真人语义双审的结果保持 pending；任何已支持的关键事实错误为 fail。
不因机械字段通过而宣称整体质量通过；收益判定保留 `Insufficient-evidence`。
若出现事实改善、过量委派、格式失败、无专家触发或较高费用，均作为有原始证据的先导观察发布。
后续正式留出和模型分配消融需另行冻结，不在这一天先导里扩张。

## 复现入口

默认零模型调用预检：

```bash
uv run python experiments/run_node_tool_study.py --output-dir reports/新的预检目录
```

演练使用 `--frozen`、`--dsh-node-modules`、`--python` 和 `--rehearse`；
真实执行另须 `--execute-paid-run`、精确的 `--approved-protocol-sha256` 与 `--approved-afp 286`。
默认产品配置、模型、思考等级、日常额度和标准模型 API 不因本研究发生变化。
