# 分用途评审回归与准入

关联 [#207](https://github.com/AEALab/RefractRouter/issues/207)、
[总计划 W06](https://github.com/AEALab/RefractRouter/issues/201)。本实现属于零调用回归和
候选审核合同，不自动改变 Task、Stage、Advisor、Escalation 的产品默认审核器或阈值。
真实评审效果仍须由 [#210](https://github.com/AEALab/RefractRouter/issues/210) 独立验证。

## 用途分开

| 用途 | 审核对象 | 不能代替的判断 |
|---|---|---|
| `task-fit` | 指定候选模型完成整个当前任务的能力与独立执行证据 | 选项概率不是任务成功率，能力描述不是经验合格率 |
| `stage-progress` | 当前步骤的进展、下一步所需能力 | 普通探索或一次失败不是停滞，历史任务名不代表当前步骤 |
| `advisor-delivery` | 最终全文、所有要求及每条附带引用 | 局部正确或几条来源存在不代表整份答卷正确 |
| `escalation-takeover` | 当前候选明确缺陷或确切停滞 | 权限、环境故障、合理澄清不等于模型能力不足 |

`purpose-review-v1` 是新候选合同，完整任务材料、完整候选、全部验收项、来源及用途共同
进入摘要。模型逐项返回 PASS/FAIL/UNKNOWN；总判词对应 ALLOW/BLOCK/UNKNOWN。
校验器拒绝缺项、重复项、只审核选定字段的声明、候选修订和不属于当前材料的引用。
每条确定判断须绑定候选原文；来源引用核对原文、整份文本哈希和 Unicode 码点区间。

`mechanicallyValid=true` 只代表结构与原文绑定有效；覆盖声明仍是模型自报。
`semanticValidityProven=false`，程序不能证明评审实际理解全文，不能据此发放产品资格。
原有产品合同继续保留，不能把研究 v2 的 `targets` 或本合同称作产品审核器已升级。

## 语义边界

采用用户已裁定的规则：明确纠正错误前提且有完整证据可以正确交付；完整上下文支持的
普通叙事推断可以接受。制帽客户不能直接变为代理关系，“唯一常见”不能确定具体物种。
每条附带引用必须支持所在段主张，附加无关引用使引用维度失败。无法裁定的边界保留未知。
这些规则进入新合同提示，仍须用独立评审结果校准，不能以提示包含规则证明模型遵守。

## 后端资格

`judge-qualification-v1` 按用途、provider、模型、模型修订、模板 SHA-256、合同版本和
实际分数阈值分组。Jev、Kimi、DeepSeek 或不同模板/修订不能继承另一组资格。
每组必须显式提供独立的准入策略，没有策略时未知，不使用全局默认成功率。

- 漏放：确定有错答卷被 ALLOW，分母是确定有错答卷数。
- 误拦：确定合格答卷被 BLOCK，分母是确定合格答卷数。
- UNKNOWN 和 FORMAT_REJECT 单独计数；不能当作正确拦截或确定语义错误。
- 未决样本被 ALLOW 另外统计，不把未知伪装成已知正确。
- 一侧 95% Wilson 上界随分母报告；0 分母为未知，少量零错误不等于零风险。

历史回归和构造协议探针不进入独立校准分母。独立材料重复使用来源簇会阻止准入；
未知率和格式拒绝率只在该独立批次计算，不能用大量旧题稀释。任何已确认历史反例被放行
都阻止这一精确版本准入。模型修订未固定也不准入。统计函数消费调用方已核实的观察和
裁定记录摘要；它本身不会认证人类身份、生成金标或证明样本来源独立。

裁定方法仅允许来源反证、明确验收、人工裁定或待定，不接受模型多数票。
来源反例只能证明失败，不能据一条反证材料推导全文通过。全套构造测试只验证计算与
边界行为，即使返回 `qualified=true` 也不代表任何真实后端已取得资格。

## 历史重放

```bash
uv run python experiments/replay_purpose_judges.py --output-dir /private/tmp/新的评审重放目录
```

入口不接受模型调用选项；输出目录须全新，禁止混入原材料。运行前后核对输入及实现摘要，
失败保留 `failure.json`。原始响应、原程序转换和最终来源裁定分别归档在
`data/judge-regression-v1`，原历史目录和分数保持不变。

当前完整归档含两题、六份实际答卷。四条确定源码/题干反例属于三份答卷，原评审通过了
其中两份。程序重新折合全部四个交付项及附带引用的原始标签，与旧程序结果一致；
再核对反例的完整候选哈希、精确片段、来源全文哈希及字符/字节位置。
来源语义解释沿用归档裁定，程序没有自动完成自然语言语义推理。

当前结果明确拒绝该历史精确后端的新准入资格；它不是该模型的一般准确率估计。
样本已暴露、只有两类来源、模型修订未知，缺少独立校准；未评估的后端没有成功率声明。
Sphinx/SymPy 源码带原许可证，未将隐藏测试、参考补丁、凭据或账本加入评审输入。

后续仍需补齐各用途的真实后端回归、正例和边界覆盖，完成审查及全套验收，才能关闭
#207；付费复评由 #210 冻结。新准入结论仅形成版本化资格材料，不直接改产品配置。
