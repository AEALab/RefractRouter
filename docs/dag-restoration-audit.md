## 本机安装与页面验收

插件 0.16.0 已通过离线、禁用安装脚本的包管理器命令安装，现有 profile 的 bundles 保持原样。
随后 DSH 服务重启成功。浏览器确认顶部「对话」「轨迹」「任务 DAG」三个页签共存；
打开历史会话可见实际 SVG 节点、依赖箭头、模型和完成／失败状态。插件设置卡片也仍可见。

## 事故归因与改进

功能回退的根因是发布时遗漏用户已安装的开发分支贡献：原 `cbdfc6d` 含图形客户端，
后续设置版入口未整合它。安装插件 0.15.0 时没有 `refractagent-dag` 注册。
排查又只看当前分支和 Think 文字，未先查历史，错误否认了原独立页签。
现有测试全通过不代表覆盖了被遗漏的分支功能；恢复后补上两种客户端贡献共同注册测试。

审批超时是真实的部署阻塞，但不是功能丢失的根因。工具返回请求在自动审查截止前未完成；
没有用户待点的弹窗，也不能从此推断安全拒绝或超时的内部技术原因。
多轮重复同一请求和同一解释，没有取得新证据，浪费了用户时间和 token；确切消耗未计量。

最终先读取 DSH 安装器源码，确认其转发 pnpm，并核对现有同名 bundle 已登记。
在现有 profile 目录离线运行 `pnpm add --offline --ignore-scripts` 安装本地恢复包成功，
没有执行安装脚本，bundles 保持原样；随后服务重启成功。
该成功仅证明这次受限路径可用，不能证明 DSH 包装器、工作目录或命令文本是审批超时原因。

只修授权范围，以及跨轮保留重试计数。源码变更已提交本地；推送合并状态须另行验证。
