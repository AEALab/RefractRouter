# 自动路由空正文与输出耗尽修复

## 原失败与核对范围

此前十二条 Direct／DAG 路线质量通过为零：八条输出耗尽、三条规划不合法、
一条交付费用事实错误。原始结果保持不变，见[完整报告](automatic-applicability-completed-report.md)。

用户另行授权最多两次 Ark `deepseek-v4-flash` 诊断，复用此前失败的公开
`request-envelope` Direct 请求，不调用 Judge、不执行工具、不自动重试。
每次输出上限 8192、期限五分钟；合计参考估值上界 0.262144 CNY，低于获授权 0.27 CNY。
不修改提供方全局推理默认值，不扩展为新一轮十二条实验。

## 分层实测

实验同时记录提供方 SSE、DSH 事件及 Router 桥接的正文长度；不记录请求头、密钥或
推理正文。以下来自两次实际终止回执，非根据空回复猜测。

| 指标 | 提供方默认 | 显式 low |
| --- | ---: | ---: |
| 实际发出的推理档位 | high | low |
| 提供方输入 tokens | 894 | 815 |
| 提供方输出 tokens | 8192 | 2680 |
| 提供方推理 tokens | 8192 | 1909 |
| 提供方正文长度 | 0 | 1536 |
| DSH／桥接正文长度 | 0／0 | 1536／1536 |
| 提供方结束状态 | incomplete，length | completed |
| 宿主等待秒数 | 72.482 | 26.655 |
| 固定事实检查 | 无交付 | 通过 |

在此请求上，默认 high 在产生正文前耗尽输出额度；low 得到完整正文，且原题固定
事实全部正确。输入、材料与正文上限相同，推理参数不同；提供方报告的输入用量有所不同。
这只能证明该题的参数敏感性，不能把此前八条未经分层记录的失败都认定为同一原因，
也不能推出 low 适合所有复杂任务。固定事实检查不代替完整解释质量的独立审核。

两次调用均确认用量并结算，合计参考估值 **0.090394 CNY**。
订阅路线没有单次现金分摊，不把参考估值当成 Ark 扣款；历史未知预留继续保留。
DSH SDK 未转交提供方的推理用量明细，桥接中的默认零值不用于解释推理占比，
上表使用提供方原生 `output_tokens_details.reasoning_tokens`。

## 已修复内容

1. **正文结束块**：桥接按块收集增量，收到宿主完整正文块后替换对应块，
   再按索引拼接；支持只有结束块的正文，避免重复，不混入推理。
   该缺口由宿主合同与模拟测试确认，但本次 high 的空正文在提供方层已经发生，
   不能把桥接缺口称为这次 high 失败的原因。
2. **推理等级可配置**：自动路由的每条模型路线新增可选 `reasoningEffort`。
   设置使用宿主目录的实际可选值；Python 预检拒绝不支持的值，编译到真实请求。
   旧配置仍继承提供方默认；显式 low 不修改规划路由、其他模型或提供方全局配置。
   时延画像按实际档位查询，不复用 default 的观测。
3. **规划标识**：将符合 ASCII 标识形状的连字符改为底线，同时重写父引用。
   保留原规划全文与版本化映射；节点职责、数量和依赖不变，名称冲突立即拒绝。
   不增加规划修复调用。`analysis` 不自动映射为其他职责；提示明确列出合法分析类型，
   原有严格校验继续保留。
4. **费用与质量**：错误终止仍结算有效用量，错误候选及工具不放行。
   原费用题是模型漏加已结算现金参考值，不是该批账本价格乘法错误；
   既有固定事实检查正确拒绝了 96 分的误批准，不能用模型高分覆盖事实失败。

不宣称 DAG 比 Direct 更便宜。非法类型的真实规划和完整 DAG 交付仍需另行有限验收；
