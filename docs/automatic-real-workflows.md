# 自动路由的真实工具工作流验收

## 本轮交付

核心 `0.16.29`、DSH 插件 `0.33.13`，宿主基线为 DSH `0.1.5-rc.3` 和
Codex CLI `0.154.0`。本轮不扩大收益实验，先验证可核对的读文件、修改和测试流程。
原 profile、provider、凭证、五模型池、推理等级和日常预算保留。

自动路由是独立的 DAG 研究入口。DSH 负责执行原生工具；Codex 使用标准
`refract/static` 模型接口和自己的 Agent 循环，不进入 DAG 或 Router 内部工具执行。

## 输出预测与公平对照

紧凑规划器允许每个节点提供 `expected_output_tokens`，必须是正整数且不超过
该次 `output_forecast_cap`。未提供时沿用旧版默认。该值只预测费用，不截断输出。
Direct 假设与候选 DAG 的最终交付使用同一预测；DAG 中间产物不能累加成 Direct
输出，也不能凭预测差额声称已经省钱。模型容量和实际请求仍用于安全预留。

候选模型继续按节点实测画像及原配置先验筛选；本轮不将文件修复结果伪装为
五款模型的独立节点校准，也不提高未测试模型的分数。实际选中路线的质量依据
单独展示，不能把未执行 DAG 的依据显示为 Direct 的依据。

## 等待时间与审核合同

DSH 通信层分别测量首段正文与首个工具请求。隐藏推理、空增量、用量回执不能
冒充首字。工具轮只有工具请求时，正文首字保持空值。模型首字不等于用户收到
最终答复；自动路由还需等待工具续接和必要审核，用户等待以端到端时间为准。
单次调用未重复写入单位时，展示沿用该次冻结模型或账本的单位；原调用的显式
单位优先，旧 AFP 记录也保持原单位，不读取当前设置重算历史金额。

最终审核每项最多选择八个来源编号。提示、机器可读限制与校验使用同一合同；
不删去多余引用来自动放行，不更改分数，也不增加修复 Judge 调用。
这项格式修复不证明审核器能发现全部代码缺陷。

## 固定功能验收

三条流程：DSH 单文件金额修复、DSH 两项独立金额／期限修复、Codex 单文件金额修复。
代码缺陷是公开标记的夹具，客户端真实执行工具；验收器检查未公开的边界和保护文件。
流程最多观察十次 DSH 执行调用、五分钟；原 DSH 工具配置仍为不限制，因此这里的
调用数是操作者停止界线，不宣称为新的核心硬上限。Codex 在实际派发边界硬限制八次调用。
禁止委派和 HTTP 自动重试；原失败与可能计费的预留保留。详见
[验收报告](../reports/automatic-workflows-20261009/acceptance.md)。

Codex 验收默认先预检：

```sh
uv run python -m experiments.run_codex_workflow_acceptance \
  --config <本机冻结配置> --baseline <本机模型目录> \
  --baseline-model <明确宿主基线模型> --output <新证据目录>
```

`--execute --probe-client` 核对真实客户端工具与输入，在预留及模型派发前停止。
只有冻结预检一致时才用 `--execute`。凭证通过环境引用解析，不写入仓库。
目录适配保留宿主指令；不继承基线模型的私有 `custom exec` 协议，改为声明
已接通的 function 工具能力。用户仍可自行管理原生工具、权限和上下文。

本机完整 Codex 请求的保守输入测量约 346654，包含宿主指令及工具目录；它不是
提供方 token 用量。实验据此冻结 524288 输入上界，不删除宿主内容来凑包络。

## 尚未证明的事项

两项独立修复的候选 DAG 可以并行，但 Router 最终选择 Direct，实际没有运行
该 DAG。因此本轮没有新的 DAG 费用或并行收益对照。此前三分支受控并行证据保留，
不能外推到所有文件修改任务。原两项修复漏掉默认期限为零的边界，且审核输出超限；
针对性复验通过不抹去原失败，也不证明首次完成率或通用质量。

下一步应增加实际开发节点的独立模型能力证据，并验证 DAG 与原生工具的组合
并行路径；模型先验的适用范围、工具串行性与重复输入成本仍需明确展示。
