# DAG 多任务冻结对照与费用预检

[Issue #32](https://github.com/AEALab/RefractRouter/issues/32) 要求区分拆分、调度及路由收益。
[data/benchmarks/dag-routing-v1.json](../data/benchmarks/dag-routing-v1.json) 冻结了任务、
人工 DAG、清单哈希、拆分、重复次数、六组方法、阈值及分析方式。已完成离线模拟，并执行了首轮真实调用；该轮在第一个节点的 JSON 格式契约失败后停止。
已确认生产记账为 0.0275 AFP、评审为 0，仍不存在真实最终质量或路由收益结论。

## 任务与数据拆分

任务完全使用请求内给定材料，涵盖方案比较、资金约束分析和简短改写三个任务族。
每族有 2 个校准任务和 1 个留出测试任务，共 6 个校准任务、3 个测试任务。
比较任务的独立分析分支可并行，资金约束分析包含必要依赖，改写任务只有一个节点。
具体题目、事实、验收条件和各节点指令均直接保存在协议中。

这是固定人工 DAG 的实验，隔离调度和模型分配的效果，不测自动规划器的拆分质量。
自动规划能力及对新任务的结构适应性仍需另一套授权验证。

校准任务重复 2 次：先让三个候选模型分别独立执行整个 DAG，并获得最终评审。
随后以固定参考模型该次运行的上游产物为上下文，独立探测每个节点的全部三个候选模型，
并逐项独立评审。各候选在同一探测上下文中消费完全相同的材料；该条件预测仍不能代替
下游使用实际混合模型产物的组合验证。

分层 profile 仅使用校准探测；候选单模型也仅根据本任务族的校准结果选定，进入测试后
不再修改。另存未经过约束筛选的最高平均质量单模型为质量基准；综合单模型须通过全部
校准验收且平均质量达到底线，再按质量、费用及模型 ID 排序。无合格模型则停止实验。

## 六组对照

每个测试任务重复 3 次，共 54 次测试运行；加上 36 次整图校准，共 90 次整任务运行。

| 方法 | 内容 | 用途 |
|---|---|---|
| `direct-strong` | 参考强模型单次完成原始任务 | 不拆分基准 |
| `dag-strong-serial` | 相同 DAG，全部用参考模型，串行 | 与不拆分组比较拆分效果 |
| `dag-strong-parallel` | 相同 DAG/模型，有界并发 | 隔离并发调度效果 |
| `dag-calibrated-single` | 按任务族校准后冻结的单模型，有界并发 | 单模型选择基准 |
| `dag-node-a` | 分层 profile，A 约束式，有界并发 | 节点路由效果 |
| `dag-node-b` | 分层 profile，B 加权式，有界并发 | 与 A 及单模型比较 |

所有组共用最终评审、验收要求和 provider 边界。串行组只把全局并发度改为 1，仍保留
provider 并发上限与启动间隔；并行组最大并发 2，`ark-plan` 上限 2、启动间隔 100 毫秒。
这些是单次 DAG 节点调度限制；校准探测、评审和不同任务之间不提供账户级限流。
协议按固定顺序执行，仍可能受到服务随时间变化的影响，不是随机交叉试验。

三候选和独立评审模型绑定至冻结 AFP 清单，使用 Agent Plan `/api/plan/v3`，零重试。
真实调用遇第一个不可用响应、契约错误、预算/时间不足或无可行路线便停止；有效但
质量不足的评审结果会被保留，用于排除候选或判定未达标，不当作传输错误重试。

## 预先固定的验收

选模要求节点质量代理至少 80、预测节点费用不超过 100 AFP、任务截止时间 300 秒；
B 权重为质量 0.5、成本 0.25、时延 0.25。最终收益判断还要求：

- 配对组的最终答案均通过语义验收，最终质量不低于 80。
- 候选相对基准的平均质量损失不超过 3 分。
- 成本至少降低 10%，时延比不超过 1。

分析按相同任务 ID 与重复编号配对，并按任务聚类重采样 2,000 次，固定种子 32，
报告 95% 区间。质量差下界、成本节省下界及时延比上界均须达到对应条件。
六组对照分别报告，不合并成一个总胜率。缺失配对不得报告成功。
只有 3 个独立测试任务，结果最多是探索性信号，不能证明跨任务泛化；模拟结果的
`exploratory_signal` 恒为 null，不用模拟评分证明收益。

每次部署成本包含节点调用和运行时必需的最终评审。校准、独立探测及其评审费用另列，
总实验费用全部计入双预算。这里没有模型规划调用，也没有外层 DSH 助手调用。

## 授权后真实执行

通常应先取得实验范围与双预算授权。用户已在本次 Issue #32 工作中明确说明使用
Ark Agent Plan 订阅并授权继续，不再逐项确认 AFP 预算；运行器按预检自动设置账本上限，
保留用量和路由成本指标。此偏好已记录于项目规范，不表示无限调用额度。
以下数字为执行账本参数，不表示新的现金支出；使用新的输出目录及冻结协议指纹：

```bash
uv run python -m experiments.run_dag_study \
  --execute-paid-run \
  --approved-protocol-sha256 '<获准的 preflight.json 中的协议指纹>' \
  --max-production-cost 3504.5376 \
  --max-evaluation-cost 15581.1840 \
  --output-dir /tmp/dag-study-paid-new
```

凭证通过模型清单指定的环境变量提供，不写入命令、协议或产物。指纹不符、缺少预算、
预算不足、非零重试或清单哈希变化都会拒绝运行。失败后保留已确认费用与未知用量
预留；再次运行必须使用新路径，按失败原因更新版本和证据；本次已授权范围内的修复验证
不再重复请求预算确认。

每次请求在派发前保存原始消息；响应在评分解析前保存正文与 usage，账本逐步检查点化。
产物包含协议、预检、有效模型清单和核心源码指纹、90 次运行的计划/路由/节点结果、独立观测、分层 profile、两类
单模型选择、总账本、配对分析，以及 `artifact-index.json`。失败可能只生成部分产物，
不能补造缺失评分。原始任务材料可能包含业务数据，应按实验数据权限管理。

从完整观测重新构建 profile，不会调用模型：

```bash
uv run python -m experiments.build_stratified_routing_profile \
  --observations /tmp/dag-study-paid-new/observations.json \
  --manifest data/model-manifests/volcengine-agent-plan.json \
  --protocol data/benchmarks/dag-routing-v1.json \
  --output /tmp/new-stratified-profile.json
```

真实 profile 及真实混合交接通过后，仍须单独完成 DSH 外层助手对实际任务工具的调用
验证；其模型调用范围和预算未包含在本协议中。插件安装、协议测试和模拟运行通过只能
证明相应集成路径，不能替代真实核心收益或真实宿主调用证据。

## 留出测试失败与后续边界

v3 完成 36 次整图校准、84 条独立节点观测和 16/54 次留出评分。
第 17 次留出运行的 `risk` 节点返回合法 JSON，但多了未声明的 `covers` 字段；
严格校验拒绝，两个已派发分支均结算，`answer` 未派发。已评分样本只来自一个测试任务，
所有 A/B 实际分配均为同一模型，尚无真实异构交接或完整配对收益证据。

提示词现明确要求键集合恰好等于 `contract.output.fields`，区分输出字段与执行元数据。
`data/benchmarks/dag-handoff-replay-v3.json` 对原失败节点的三个候选各回放一次，
全部通过严格结构契约；这仅是开发修复验证，不证明最终语义质量或可靠性改善。
原留出样本已经用于诊断，后续独立验收必须先冻结新的留出集；不能将修改后的回放
拼接成原实验成功。校准 profile 只覆盖本轮实际观测的三个能力分层与声明输入预算区间。

现有冻结单模型基线按校准质量优先选取，并未对整任务模型作对称的 A/B 优化。
后续若要声称节点路由优于三指标整任务路由，须先补齐这两种基线并冻结新协议。
完整结果及剩余清单见 [本轮报告](../reports/dag-decomposition/issue-32-subscription-20260907/README.md)。
