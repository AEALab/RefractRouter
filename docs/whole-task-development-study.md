# 整任务与事实工具的独立开发筛选

关联 [#210](https://github.com/AEALab/RefractRouter/issues/210)，承接
[总计划 #201](https://github.com/AEALab/RefractRouter/issues/201)。本入口仅供研究宿主使用，
不改变标准模型 API、四策略或 DSH 默认配置，不执行 DAG。

## 问题与可解释范围

先比较固定强模型 S0、固定弱模型 W0、同一弱模型可使用事实工具 WF。
三组均直接完成整题，没有模型规划、节点执行、在线模型评审或失败后强模型回退。
WF 可使用的两个工具只读取其他两组已经获得的同一份可见资料，不增加外部知识。
工具由研究宿主调用，不由 Router 启动 Agent 工具循环。

六道新开发题每类两道：确定性提取、跨文件受控修改、证据约束分析。
来源分别是 Click、platformdirs、urllib3、cachetools、httpcore、AnyIO 的固定公开提交。
这是人工定义、可完整机械验收的受控任务，不能称为六份自然缺陷票据，也不代表开放代码修复。
公开源码可能已进入模型训练；项目来源隔离不等于训练污染已排除。

旧两道研究题不计入新样本。每类的第一题进入预冻结半批 0，第二题进入半批 1。
按固定随机种子交错路线顺序。模型重复回答同一题不会增加独立任务数。
24 道留出题只预留名额（每类 8 道），当前未采集材料、未查看答案、未执行；
只有开发筛选显示具体增益后才考虑独立采集。不得将名额写成已冻结完整留出题。

## 交付与评分合同

每份答卷恰含 `answers`、`evidence`、`edits`，字段和原生值类型在题目中列明。
事实值按固定源码确定；引用必须逐字符存在、属于正确符号范围，并覆盖人工冻结的完整支持片段。
允许组合多段原文，允许预先登记的文档/实现替代证据。每条附带引用都必须相关，
附无关或重复引用也判引用失败，沿用用户已裁定的严格口径。

引用校验只检查人工指定的支持片段，不是通用自然语言蕴含判断。
冻结片段本身须经人工或独立代码审查，不能仅用相同词语出现证明语义。
原文引用过窄或缺少条件，与事实值错误分维度报告；不在看到答卷后改评分挽救失败。

受控补丁仅允许指定常量或默认参数变化；在内存替换后，按 UTF-8 文件字节解析 Python AST，
与冻结目标 AST 比较，其他文件字节保持。允许排版差异，拒绝无效编码、额外行为和改错分支。
不运行或导入候选代码。这只完成这些明确限定的修改任务，不证明开放补丁能通过真实项目测试。

生成模块不导入评估器、不读取 oracle。`visible/` 是模型和事实工具的全部可读资料，
`isolated-evaluation/` 保存评分材料；工具的固定根目录和哈希清单排除后者。
评分使用单独入口，清除认证环境并阻断 Python 网络和子进程操作。
这属于程序边界，不冒充 OS 级隔离；不把隐藏答案、参考解或评分日志回传给答题模型。

## 模型与调用包络

使用 Ark Agent Plan `/api/plan/v3`：强模型 `ark/glm-5.3`，弱模型
`ark/glm-5.3-flash`；温度 0、思考开启、`reasoning_effort=low`。
不使用其他 provider 的同名模型，不启用强制 `response_format`。
记录实际返回模型身份；未版本化别名不能保证未来版本稳定。

原生回答容量取官方示例的 131072，`max_tokens` 保留该值。
官方模型资料及接入示例存在 128000/131072 与 1024000/1048576 的单位差异，
因此输入容量采用较小值 1024000，费用采用较大共享上下文上界 1048576。
参数被供应商拒绝时保留错误和预留，停止诊断，不自动换参数重试。

Ark 文档明确 `max_tokens` 对 GLM 限制回答，思考另外计入 `completion_tokens`。
因此不能以“输入上界＋回答上限”作为全部输出的费用上界。
本研究显式启用 `context_token_envelope`：以共享上下文乘固定最高边际单价保护总费用，
保持线缆回答上限不变；未知用量保留整个预留。已知用量超包络或无法确认回答上限时，
先结清已知费用再停止，不接受该候选。动态价格与此包络混用会被拒绝。
本选项不会自动应用到既有产品配置；既有产品原生输出语义仍需独立迁移验证。

最多 36 次 HTTP 请求：S0 六次、W0 六次、WF 每题最多四次，共最多二十四次。
WF 每题最多八个本地工具查询；没有额外模型路由或模型评审。
保守输入字节包络 512000，单次等待 600 秒，整批时间盒 10800 秒。
零 HTTP 自动重试。模型返回已知失败计费用并保留，认证、未知用量或证据写入异常停止整批。
所有尝试、原请求及响应、实际身份、用量、费用和工具耗时写入新的私有证据目录。

## 费用与授权承接

官方 Agent Plan 标准 AFP 系数：GLM-5.3 输入/输出均为 4.5/万 token，Flash 均为
0.5/万 token。本批最坏保护 4404.0192 标准 AFP。全部思考、工具续接输入和失败尝试计入。
不将本地工具称为零资源成本；另列工具耗时，工程与人工投入不冒充在线模型费用。

财务承接固定到 2026-10-29 既有研究结算文件的原字节哈希：
累计现金保护 26.3507702502422 CNY，含未知现金预留 12.058624 CNY；
累计授权 300 CNY，条件余量 273.6492297497578 CNY。
既有已知标准 AFP 18825.19320，未知标准 AFP 预留 4988.87680，继续保留。
现金条件余量不是供应商账户余额。使用用户已说明无超额后付费的 Plan 时，本批新增现金条件值为 0；
额度不足可以由 provider 拒绝，不能自动切到现金付费端点。
实际 `PlanChargedAFP` 未核对；标准 AFP、实际扣减、现金、订阅费分别表达，不换算相加。

## 判定与停止

逐题同时报告完整合同通过、答案、引用、补丁，以及“强模型通过而候选未通过”和反向改善。
不得删除失败或只对成功项统计节省。未知评分不成为零损失或改善，未完成不报整批节省。
完整费用目标至少省 20%，预冻结两个半批都省钱，无新增关键缺陷；等待时间另列全部观测，
不以低费用掩盖等待。研究机械评分模型调用为 0，单列其本地耗时。

质量差值使用保守单侧 95% 配对损失率上界；允许差值下界不低于 -3 个百分点。
该区间需要独立任务假设和来源审计。六题、甚至二十四题零观测损失都无法证明这一门槛；
筛选器始终不授权发布。证据不足、工具无增益、明确回退、预算不足或时间盒耗尽时，
给出停止或有限继续结论并保持默认。最多一次有具体错误依据的开发修订，另开目录，历史不改。
不自动扩量追显著性，不跳到 Task/Stage/Advisor/Escalation/Composite 大矩阵。
