## 当前证据和因果边界

Claude 文章仅提供研究假设，未提供可复核的样本、配对和评分口径。
现有历史实验仍保持 `Insufficient-evidence`；不重写历史结果或放松 Go/No-Go。
本轮 P0–P1 使用模拟模型，只判定工程契约，不能作为任务质量判定。

Issue 原三臂表述需收紧：node-as-tool 保持主历史，专家仍有独立输入及交接。
one-shot 与专家工具路线还同时改变了调用次数、任务提示、委派和结果整合；
工具路线与 DAG 还改变了调度和上下文投影。不能把差异全部归因为模型切换或交接损失。

## 付费对照设计草案

| 臂 | 执行方式 | 用途 |
|---|---|---|
| A | 已优化 prompt 的 one-shot | 直接完成任务基准 |
| B | 主循环与专家工具，固定模型 | 专家交互固定模型对照 |
| C | 与 B 相同工具合同，规则 Stage 选模 | 同一交互架构下的路由策略处理效应 |
| D | DAG 所有节点固定同一模型 | DAG 固定模型对照 |
| E | 同一 DAG 的 node-mixed | 同一 DAG 下逐节点选模的处理效应 |

C–B、E–D 是优先配对；涉及架构变化的 A/B/D 比较仅报告整体方式差异。
C 与 B 的模型输出仍可影响后续工具选择，故测到的是策略总效应。
若要进一步分离交接损失，需要额外固定调用计划、输入视图、输出容量和模型分配的实验，
不能由这五臂直接识别。

所有路线使用同一公共任务 payload、交付与事实验收合同、材料版本、模型版本及定价快照。
主循环可见信息与专家投影规则必须归档；工具调用、结果及事件时间戳保留，便于回放。
执行模型不读取私有参考答案或路线偏好。冻结回退规则，底层 HTTP 重试为零。

## 数据与公平性前置

先审计 `data/benchmarks/v0.1.json` 的 train/test/pilot 与历史使用重叠，记录任务 ID 和哈希。
该集合是报告生成合成任务，不能代表通用 Agent 工作。`data/quality-study-v1` 的候选留出集
也须完成既有材料审查后才能当作独立最终质量证据。当前不声称已冻结付费测试集。
先在开发集进行有界 one-shot prompt 审查和改进并记账，冻结后才能进入留出对照。
不得观察留出结果后调整提示、节点模板或策略，再把同一集合当成未见测试集。

## 调用与预算冻结

每臂每任务至少 3 次重复，按任务、重复号与版本配对；不跨轮拼接，不补零。
工具臂的调用包络应为 `主模型请求上限 + 专家调用上限`，两类调用共用父账本；
例如本轮离线夹具是 4 次主模型请求 + 3 次专家请求，而不是 3 次总模型请求。
再加上全部任务、重复、基线改进和独立评审，计算每种币种的最坏费用并冻结。

Issue 建议的 60 AFP 尚未获付费批准，也尚未证明能覆盖完整五臂。
真实模型清单若使用新版金额计价，则使用对应 CNY/参考成本预检，不机械写成 AFP。
只有明确范围和预算授权后才可 P2 真跑，使用新的证据目录，不调整日常插件额度。
认证、未知用量、账本或证据写入异常停止整批；任务失败停止下游并保留在途结算。
不自动重试，不用下一批掩盖失败或未知预留。

## 结果与裁定

逐任务输出 pass→fail、fail→pass、稳定通过、稳定失败及 pending 的翻转矩阵，
并报告完整可配对数、失败与拒绝，不只报告均值。报告配对质量、全部模型费用、
评审费用、端到端时延、关键路径、缓存用量、调用次数及 Pareto 表。
模型评审和 `replay_cheap_judge` 作为辅助；最终质量沿用既有确定性关键检查与独立真人语义双审。
缺审查、意见冲突或缺配对证据保持 pending／`Insufficient-evidence`。

判定阈值须在付费测试前按既有质量协议冻结。质量门槛优先，然后比较总成本与等待时间。
若没有可信净收益，发布适用边界与反例；不据此关闭 direct-or-DAG 研究或修改默认策略。
