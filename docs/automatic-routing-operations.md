# 自动路由日常使用、故障处理与回滚

本文说明如何使用 DSH 中的 RefractAgent 自动路由、阅读路由轨迹、处理常见停止状态，
以及在出现问题时关闭真实执行。当前功能边界按 RefractRouter 核心 `0.16.20`、
DSH 插件 `0.33.4` 核对；这些说明不代表其他宿主或标准模型 API 已通过同样验收。

## 选择入口

在 DSH 模型选择中：

- `RefractAgent · 自动路由（模拟）` 用于查看模拟拆分流程，不调用真实模型。
- `RefractAgent · 自动路由（真实执行）` 在当前自动路由配置、数据域和额度允许时，
  对新任务执行零调用预检并调用真实模型。
- `RefractAgent 规划路由` 使用所选规划策略，保留宿主 Agent 循环；它不是 DAG 自动路由。

自动路由先检查已配置的模型、数据域、容量、工具限制和预算，再分析任务是否值得拆分。
“可拆分”表示规划探测可以提出 DAG 候选，不等于最终一定执行 DAG。核心还会比较合格的
Direct 与 DAG 路线，并可能选择整任务 Direct。只有轨迹中的最终路线标记为 DAG，才表示
该运行实际采用节点图。

选择模型和处理费用由 Router 负责。工具权限、审批、会话和任务推进仍由 DSH 宿主负责；
自动路由不能绕过宿主权限，也不能把没有可信状态的工具回执当成模型能力问题。

## 设置及最终纠正

自动路由配置位于「设置 → 插件 → RefractAgent 自动路由」卡片，和规划路由设置分开。
真实任务需要先启用真实执行、配置模型池和计费组，并选择合适的数据模式。
`live` 数据模式只允许已配置为本地或可信云、且信任策略符合本次数据的模型路线；
不要为了解决排除提示而扩大云端信任范围。

「审核拒绝后纠正一次并复审」默认关闭。开启后，如果最终审核拒绝尚未交付的候选：

1. 原最终执行模型收到受约束的纠正反馈。
2. 已完成的规划、DAG 节点和工具不会重做。
3. 纠正后的候选必须通过复审才交付；复审仍不通过就停止。
4. 派发前会预留一次纠正和一次复审的额度；未用到的保护额释放。

纠正不是一般失败后的自动重试。规划格式错误、认证／传输失败、用量不明、审核回执
非法或证据写入失败时，系统按错误类别停止，不通过切换模型或自动 HTTP 重试掩盖问题。

## 阅读路由轨迹

在「路由轨迹」中按以下顺序查看一次任务：

1. **最终路线**：查看实际是 Direct 还是 DAG，以及运行是否完成、停止或中断。
2. **选择原因**：区分规则／Judge 的拆分建议、规划器给出的 DAG 候选和核心最终选择。
3. **实际调用**：检查每次调用的用途、真实 provider/model、推理等级、输入输出用量、
   耗时和结算状态。
4. **最终审核**：查看候选是否接受或丢弃、判定理由；若启用纠正，查看首次候选、
   纠正及复审各自的状态。
5. **费用与等待**：分开读取按量现金、订阅路线参考估值、未派发保护额度和待核对预留。

模型目录价格算出的参考估值不是提供方账单，也不等于实际扣款；订阅模式不会按单次调用
生成现金扣款记录。底层模型首字时间也不是用户从发送到收到答案的完整等待时间。完整字段
边界见[自动路由轨迹说明](automatic-routing-trace.md)。

## 常见停止状态

| 轨迹现象 | 处理方式 |
|---|---|
| 没有合格候选或模型因数据域被排除 | 核对模型池、数据模式与该路线已有信任设置；只在确认数据可发送时调整信任策略。 |
| 额度或模型容量不足 | 查看轨迹列出的具体用途与候选；按实际需要调整对应配置后，用新任务重新验证。 |
| 规划未形成合法 DAG | 本次不会执行不合法计划；查看规划错误及输出限制，不把失败任务标成 DAG 成功。 |
| 最终审核拒绝且纠正关闭 | 候选未通过审核；可检查审核依据，选择是否启用一次纠正，再以新任务验证。 |
| 纠正复审仍拒绝 | 候选不交付；检查首次问题、纠正反馈及复审结果，不重复执行已完成工具。 |
| 认证、传输、用量未知或账本错误 | 本次受管流程停止；先核对提供方和账本状态。未知用量保留预留，不按零费用处理。 |
| 页面状态与已结束运行不一致 | 先刷新同一会话并查看持久路由轨迹；保留运行 ID 和停止原因供排查。 |

修复配置后，应发送新的任务验证。系统不会因为再次打开旧记录而重新派发调用。

## 回滚真实执行

发生持续故障或需要暂停真实调用时，在原 DSH profile 的自动路由设置卡片中关闭「启用开发
真实执行」，或将新任务的数据模式恢复为之前已核准的模式。保存后，新任务将按新配置进行
预检；已经启动的任务仍使用启动时冻结的配置和授权。

回滚不要求删除模型、provider、凭证、会话或路由记录。保留运行 ID、错误阶段、已结算费用
及未知用量预留，便于之后复核。关闭自动路由真实执行不会关闭规划路由，也不会修改 DSH
其他模型入口。
