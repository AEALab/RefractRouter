# 自适应最终审核

这是自动路由的最终候选审核，独立于规划 Advisor／Escalation 的设置与状态。
当前规则为 `adaptive-final-review-v1`，适用于新版人民币参考计价配置。

## 哪些任务需要审核

预检先保护可能需要的审核路径。最终候选形成后，根据原任务风险与实际证据决定派发：

| 情况 | 行为 |
| --- | --- |
| 低风险 Direct，未出现额外风险 | 可以跳过付费审核，记录跳过原因 |
| DAG、明确资料与验收合同、事实查证等 | 保留审核 |
| 实际工具结果、引用、候选断言实现／验证状态 | 纳入审核风险检查 |
| 仅仅注册了可用工具 | 不单独触发最终审核 |
| 选择始终审核 | 每次保留审核 |

规则决定是否增加审核，不凭关键词直接认定事实错误或答案通过。
预检未保护的微型路径出现新审核风险时停止交付，不能事后任意扩大调用路径。

## 审核材料怎样组织

完整任务、候选、验收条件与工具记录按值去重，保留原始数值、文本、来源、工具参数、
调用与结果配对。候选与来源分开，候选不能用自身为事实自证。
材料不截断、不隐式摘要，不增加摘要模型调用。派发前核对实际模型上下文和明确输出上限。

公开合成夹具输入由 239426 降至 104200 字节，完整工具值还原相等。
这是该夹具的结果，不代表所有任务同比节省费用或提高准确率。

## 不同失败如何处理

| 核心结果 | 后续行为 |
| --- | --- |
| 明确候选缺陷 | 若已启用最终纠正，原执行器纠正一次，再复审 |
| 证据检查无法判断 | 未审定停止，不用文字补造证据 |
| 没有明确缺陷但分数未达门槛 | 停止，不盲目返工 |
| 非法审核、认证／传输故障或未知用量 | 停止后续调用，保留错误与费用 |

纠正不重建 DAG、不重跑已完成工具、不追加子 Agent。
自动路由最终审核的结论不会反向改变已完成节点的选模；规划 Escalation 的接管是另一策略。

## 时间与额度

审核模型与推理等级独立配置。审核等待是派发后的上限，审核预留是执行阶段提前留下的
任务余量，两者用途不同。180 秒设置仍受任务剩余期限约束，不保证提供方按时完成。
执行输出与审核输出容量分开；推理 token 是否计入输出以实际接口为准。
