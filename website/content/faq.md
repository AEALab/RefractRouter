# 常见问题

## 为什么模型列表只有旧的三个档位？

“省成本／均衡／质量优先”属于旧配置。核对实际核心、插件、当前 profile 和模型池初始化状态。
新版自动模型池配置会提供自动路由入口；规划入口提供独立六策略。
不要切换到新 profile 以掩盖原模型和会话丢失。

## 为什么 Jev 或本地 Laya 不在审核 LLM 下拉框？

它们是不同的 Judge 接口，在策略的“审核器／Judge 类型”中选择。
Advisor 审核 LLM 下拉只列普通 DSH LLM。另在官方 Jev 区域选择 OpenRouter、凭证引用及信任策略。

## 什么是零调用诊断？

在发模型前核对配置、能力、价格、预算、信任和协议组合。
它不测试 provider 远端可用率、不评价 Judge 质量，也不承诺省钱。

## 为什么出现 local-absolute-path？

DSH 系统上下文可能包含本机绝对路径。当前目标路线的数据域不允许发送该类输入。
在对应路线设置中登记你认可的可信云策略，或改用符合要求的真实本地路线。
一种 provider 的授权不自动扩大到其他 provider。

## replay 组合未经验收怎么办？

模型历史必须保留真实来源、工具配对和实际 replay。核对组合是否已适配，不能直接删除
来源或把所有历史改标当前模型。未验收组合按准入提示处理。

## inputPer1k 或价格未完成怎么办？

核对实际路线、计价单位、价目表与版本映射。新配置使用 CNY 参考与现金两种账本，
不再把 AFP 当作金额。刷新或补齐已核对资料；不要填零价格来绕过预算。

## 429、用量未知或等待超时会自动重试吗？

不会。当前模型传输保持零自动 HTTP 重试。提供方过载属于基础设施故障，
不是用户漏批，也不是模型能力升级信号。已派发但用量未知保留预留，停止当前受管路径。
有界节点切换或策略接管是显式策略行为，与传输重发分开记账。

## 模拟回答为什么不理会我的真实问题？

模拟或验收夹具只用于接线。选择真实模型入口，完成零调用诊断与真实执行配置，
再新建任务；不要把“离线验收完成”当成模型实际回答。

## 为什么能拆分却选择 Direct？

能拆分只是结构信号。Python 还需检查质量、数据域、预算、期限及规划／汇总开销。
查看实际路线理由；没有真正执行 DAG 时不能进行实际费用比较。

## 为什么 DAG 的节点用了同一个模型？

合格模型池不等于必须均匀分配。节点证据、能力档案、推理等级、费用和数据域可能让同一路线胜出。
缺少差异化依据时应显示先验来源，不能为了图形好看强制异构。

## 本地 Judge 就一定更便宜、更快吗？

它没有 API 费用，但有资源、冷启动和排队成本。速度与判别质量要分别验收。
当前 Laya 的多个用途未达到日常质量要求，保留实验状态。

## 是否支持完整图片／影片任务和共享子 Agent 预算？

当前完整产品验收聚焦文本与原生工具。图片相关路线有部分接线，但完整真实矩阵仍未完成；
原生影片、图片／影片审核与 P6 共享预算另行验收。能力标签不能代替实际接通。
