模型、费用与数据域 ​

选择“模型”实际是在选择 provider＋模型版本＋接口＋推理参数 的路线。 同名模型在不同提供方可能有不同容量、价格、工具或 replay 限制。

模型资料 ​

DSH 目录与凭证共用，规划路由和自动路由的选择与运行状态分别保存。 系统资料包括上下文、输出容量、推理等级可选范围、缓存／输出价格、来源和查证日期。 资料缺失、版本映射不明或接口能力未知时，诊断说明缺项，不默认为免费或支持。

能力区分提供方声明、适配已接通与该路线已验收。 文本、工具、图片输入、影片输入、图片输出与影片输出分别检查；不要仅按模型名称推断。

新配置使用 CNY，不再按 AFP 计价 ​

Ark 订阅执行接口仍保留。新账本把参考估值与按量现金分开，USD 原价同时保留汇率、 来源与日期；不把订阅点数换成人民币。

费用列含义
参考成本使用明确对应公开价格，对模型用量形成可比较的估值
按量现金需要另外支付的 API 金额，按可核对回执／计价合同结算
未派发保护为审核、返工或接管等必要路径保护的额度
待核对预留已派发但用量／结果未确认，继续保留的额度

**参考与现金不能相加。**订阅月费未按调用分摊时，不把参考估值称为实际扣款， 也不因为新增现金为 0 就宣称模型免费。质量合格后可以优先订阅路线，再比较参考成本与时延。

历史 AFP 配置与原始记录按原版本读取，不追改费用，也不把旧 AFP 授权转换成 CNY。 旧配置需要显式升级；预算变化必须由用户确认。

预算与限制 ​

规划路由的预算、期限与最大调用数支持 0＝不设 Router 上限；实际仍受模型容量、 提供方限制和技术上限约束。自动路由按设置中的明确“不限”选项处理，不把所有数字 0 笼统解释成无限。审核与执行的输出上限也不完全相同。

只为选中的互斥执行路线预留；确实可能先后发生的执行、Judge、返工与接管路径需要保护。 未知用量不自动释放预留。宿主其他工具与独立子 Agent 费用不在当前主任务硬预算覆盖内。

数据域与信任 ​

选择含义
本地真实本地部署路线，仍按数据与能力规则检查
外部云默认保守检查，可能拦截本机路径或敏感输入
可信云绑定用户明确登记的信任策略，允许该策略规定的外发范围
模拟本地实验标识，不是实际本地计算或云端授权

可信云不表示模型更聪明、不减少费用，也不绕过接入方的工具权限。 对 Ark 的授权不自动覆盖 DeepSeek、Kimi 或 Jev。Jev 经 OpenRouter 时，OpenRouter 与 TypeSafe 都涉及判别数据传输，应按实际渠道配置。

为什么会显示不同的审核角色 ​

  • 兼容旧策略的判别 LLM：服务旧版 Task／Composite／Escalation 等共享判别配置， 不自动替代新版独立 Judge。
  • Advisor 审核 LLM（DSH 模型）：仅在 Advisor 选择 LLM 审核器时使用。
  • 官方 Jev／本地 Laya：通过策略的 Judge 类型选择，使用独立接口，不是上述 LLM 下拉项。
  • 自动路由最终审核模型：服务自动路由的最终 Judge，与规划角色分别配置。
