# 独立 Judge Rubric v0.1

真实模型实验使用不在候选模型池中的独立 judge。Judge 只能使用冻结 source pack，
输出固定 JSON，包含五个评分维度、逐条 expected claim 的支持关系和简短理由。

最终分数不是直接采用 judge 总分：需求覆盖、证据准确性和 HTML 有效性分别取
确定性检查与 judge 评分的较低值；分析深度、结构与可读性采用 judge 评分。
只要最终 HTML 的 source trace 存在问题，证据准确性直接归零。

| 维度 | 上限 |
|---|---:|
| requirement_coverage | 25 |
| evidence_accuracy | 25 |
| analysis_depth | 20 |
| structure_readability | 15 |
| html_validity | 15 |
