第 0 天开始，按连续执行、不考虑周末计算。

## 一、排程核对

### 1. 各工作最早开始与完成时间

| 工作 | 工期 | 依赖条件 | 最早开始 | 最早完成 |
|---|---:|---|---:|---:|
| A 手续 | 2 天 | 无 | 第 0 天 | 第 2 天 |
| B 运输 | 3 天 | A 完成后 | 第 2 天 | 第 5 天 |
| C 版面设计 | 4 天 | 无，可第 0 天独立开始 | 第 0 天 | 第 4 天 |
| D 布展 | 2 天 | B 和 C 都完成后 | 第 5 天 | 第 7 天 |
| E 验收 | 1 天 | D 完成后 | 第 7 天 | 第 8 天 |

说明：  
- B 必须等 A 完成，因此 B 最早第 2 天开始，第 5 天完成。  
- C 第 0 天开始，第 4 天完成。  
- D 必须同时等 B 和 C 完成。B 第 5 天完成，C 第 4 天完成，因此 D 最早第 5 天开始。  
- E 在 D 完成后开始，因此第 7 天开始，第 8 天完成。

### 2. 总工期

总工期为 **8 天**，即第 0 天至第 8 天完成。

### 3. 关键依赖链

决定总工期的关键依赖链为：

**A → B → D → E**

对应时间为：

- A：第 0—2 天，2 天  
- B：第 2—5 天，3 天  
- D：第 5—7 天，2 天  
- E：第 7—8 天，1 天  

合计：2 + 3 + 2 + 1 = **8 天**

C 虽然需要 4 天，但第 0 天即可开始，第 4 天完成，早于 B 的第 5 天完成，因此 C 不在关键链上。

## 二、费用核算

已给出的费用为：

| 费用项目 | 金额 |
|---|---:|
| 采购 | 1200 元 |
| 运输 | 800 元 |
| 布展 | 1500 元 |
| 设计 | 900 元 |

总费用：

1200 + 800 + 1500 + 900 = **4400 元**

总预算为 **4600 元**。

预算余额：

4600 − 4400 = **200 元**

因此，费用未超预算，余额为 **200 元**。

## 三、如果 C 额外延误 2 天

原计划中 C 的完成时间为第 4 天。如果 C 额外延误 2 天，则 C 的完成时间变为：

第 4 天 + 2 天 = **第 6 天**

此时需要重新判断 D 的开始条件：

- B 仍为第 5 天完成。  
- C 延误后第 6 天完成。  
- D 必须等 B 和 C 都完成，因此 D 最早开始时间变为第 6 天。

调整后的排程：

| 工作 | 最早开始 | 最早完成 |
|---|---:|---:|
| A | 第 0 天 | 第 2 天 |
| B | 第 2 天 | 第 5 天 |
| C | 第 0 天 | 第 6 天 |
| D | 第 6 天 | 第 8 天 |
| E | 第 8 天 | 第 9 天 |

调整后总工期为 **9 天**。

关键依赖链变为：

**A → B → C → D → E**

或更准确地说，由于 C 延误后成为 D 的约束条件，关键链为：

**A → B → D → E** 与 **C → D → E** 汇合后，由 C 的延误决定 D 的开始时间。

因此，C 额外延误 2 天会导致总工期从 8 天增加到 **9 天**，即整体延后 **1 天**。

## 四、最终安排

- 原计划总工期：**8 天**  
- 关键依赖链：**A → B → D → E**  
- 总费用：**4400 元**  
- 预算余额：**200 元**  
- 若 C 额外延误 2 天：总工期变为 **9 天**，整体延后 **1 天**，费用不变。
