## 对后续比较的解释约束

- 当前三个构造任务存在字段值正确率的上限效应，不能据此预设需要更多专家才能算对。
- 专家仍可能在相同正确性下减少总思考输出、模型费用或等待，必须计入规划、专家及汇总的全部开销。
- 引用补全与数值改进分开解释；不得把只有引用改善的变化称为新算对了事实。
- 正文回读发现的窗口等待表达歧义仍保留为待澄清，不改字段主判据，不当作独立人工双审。
- 提示选择继续等待完整 18 样本，按原冻结规则执行；不根据本诊断改提示、任务、路由或评分。
