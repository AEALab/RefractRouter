# #52 质量协议、真实校准与材料修订证据

本目录归档三类任务质量协议的开发检查和辅助模型真实校准，不是路线收益实验。
协议与运行方式见 [质量协议](../../docs/quality-study-protocol.md)。
实测、标签分歧和材料修订见 [真实校准分析](model-calibration-analysis.md)。

## 已验证的范围

- 18 个原创虚构任务：6 开发、12 候选留出，三类任务与三种结构形态均有覆盖。
- 评分校准只使用六个开发任务；当前19个样例包括12个修订正例/等价表达与7个负例。
- 5 个负例被确定性检查判为失败；反写依赖和漏抽样限制两个语义负例仍待真人判定。
- 首批36次真实调用、39.796 AFP：6个作者负例全部被模型拒绝；
  12个作者正例中10个通过，2个因同一道问卷答案漏项被拒绝，原始标签与分歧保留。
- 已修订问卷答案及5份材料的公开提示，另行冻结11次定向复查；结果见分析及原始归档。
- 定向复查11次、12.394 AFP：四个正例通过、两个负例失败，
  材料检查中一次总体/分项矛盾被程序留待判定。两批合计47次、52.190 AFP。
- 模型意见均标为 AI；真人记录为0，真人分歧未知，不写成0或伪造通过。
- 两次路线预检本身都是零调用、零AFP；付费辅助评审另列，不能把预检的0当成整个工作的消耗。

## 包络的含义

`preflight-01/preflight.json` 列出12条候选路线、3次重复的最大容量包络。
开发侧216个候选运行、最多1404次调用；候选留出侧432个运行、最多2808次调用。
这些数字是把每条路线都跑满上限的声明，**不是本轮已经执行或获准执行的批次**。

按冻结 manifest 最大未缓存容量计算：

| 分组 | 在线 AFP 上界 | 独立研究评分 AFP 上界 |
|---|---:|---:|
| 开发 | 24783.8544 | 7520.2560 |
| 候选留出 | 49567.7088 | 15040.5120 |

该保守上界明显高于短任务的预期实际用量；它不能用作预计账单。
离线画像/训练/搜索尚无包络，因此还不是研究总预算。
真实 runner 的逐请求容量、deadline 与预算预留也未绑定，`formal_run_ready=false`。
正式冻结时须先用开发证据收窄实际可行路线与容量，另出新版本。

## 归档目录与文件

- `preflight-01/`：首版零调用草案快照，保留原18个开发样例。
- `preflight-02/`：材料及参考答案修订后的零调用快照，19个开发样例。
- `model-calibration-01-preflight/` 与 `model-calibration-02-preflight/`：两批真实调用前的冻结请求、代码哈希及上限。
- `model-calibration-01/` 与 `model-calibration-02/`：原始模型响应、会话账本、分析计数及文件哈希。

各 `preflight-*` 下的文件用途如下：

- `protocol.json`：当前草案快照。
- `preflight.json`：材料检查、开发评分校准、路线包络与计划运行顺序。
- `execution-inputs.json`：公共执行输入，不含参考答案与路线标签。
- `material-review-packet.json`：独立材料审核空表及材料/参考事实。
- `blind-calibration-packet.json`：供真人校准评审的匿名样例，意见栏为空。
- `private-blind-mapping.json`：只供协调者解盲，不能和盲审包一起交给审查者。
- `artifact-index.json`：上述文件的哈希。

机器检查、AI 意见和盲审模板都不是真人签署的证据。#52 仍需材料独立审查、
用途校准、真人盲审、校准分歧裁决与实际路线冻结后才可关闭。
