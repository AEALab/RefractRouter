## 真实 Jev 判断

冻结六条合成案例，两条微型任务零调用，四条调用 OpenRouter 的
`typesafe/jev-1.13-20260917`。每次两项 Noul，门槛 0.65、零 HTTP 重试。

| 案例 | 预期 | 实际 |
| --- | --- | --- |
| 两项封闭算术 | 跳过判别与规划 | 符合 |
| 单句定义 | 跳过判别与规划 | 符合 |
| 独立合同审查 | SEPARABLE | 符合 |
| 测试堆栈驱动的修复链 | COUPLED | 符合 |
| 独立模块审计 | SEPARABLE | 符合 |
| 未知 schema 驱动转换链 | COUPLED | 符合 |

实际四次耗时 639／487／482／465 ms，总费用 0.0007006696494 CNY。
首次调用 639 ms，其余三次中位数 482 ms；不把小样本视为稳定性能指标。
预期标签由开发者冻结，用于功能验证，不是独立质量数据集。

首次真实回答暴露合并规则缺陷：工具关键词仍把两条 COUPLED 变成 DAG。
修复后使用相同回答做零调用回放，六条最终门控均符合预期；原始错误没有覆盖。
回放及原始结果摘要哈希见 `gate-replay.json`。

## 真实执行

使用已安装 DSH 模型适配器、DeepSeek 官方 `deepseek-flash`，推理 `low`，
合成文本任务，无委派、无传输重试。复用已取得的 Jev 回答，不再调用 Judge。

| 批次 | 实际结果 | CNY |

不能解释为独立专业正确性验证。8192 只用于新冻结验收，没有调整用户单任务配置。
初始执行上界 1.179648 CNY，针对输出截断的独立复验上界 0.589824 CNY。

两种候选均通过准入，但 direct 费用较低，所以执行 direct，未实际运行多节点。
8192 批次 direct／DAG 保守总费用预测分别为 0.27792212／0.45050012 CNY，
这是包含输出上限的预测，不能当成已产生费用。

输出截断费用已计入，没有只保留成功调用。
