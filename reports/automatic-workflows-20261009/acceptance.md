# 真实文件工具工作流验收

## 结论

本轮验证 DSH 自动路由和 Codex CLI 标准模型接口的真实读写文件、测试及工具续接。
DSH 单文件与 Codex 单文件各通过十项独立检查；DSH 双项任务首次失败，针对性修复后
通过二十项检查。首次失败保留，不把复验合并成首次成功，也不据此声称 DAG 降低费用。

PR [#194](https://github.com/AEALab/RefractRouter/pull/194) 已合并。本轮新增修复与验收
另行提交。实现说明见 [真实工作流设计](../../docs/automatic-real-workflows.md)，
可核对的调用摘录见 [验收数据](acceptance.json)。完整原始请求、宿主上下文、工具回执、
候选正文与日志保留在本机原证据目录；公开摘录不包含凭证和完整用户上下文。

## 发现与修复

### 最终审核没有获知已有引用上限

双项首次输出遗漏 `timeout_seconds(None, default_ms=0)` 的不限制语义。
已有审核器给出 95 分，但使用十三个来源编号，超过核心已有的每项最多八个限制，
因此 Router 拒绝交付。独立检查发现期限边界仍有错误。

修复把引用上限同时写入提示和结构化合同，保留严格校验；不裁剪引用、不更改分数、
不增加审核修复调用。另以新任务修正已发现的期限边界，原客户端真正执行修改和测试。
复验通过不证明审核器能发现所有代码缺陷；独立可执行检查仍不可用模型自评分替代。

### Codex 目录继承了不兼容的私有工具协议

本机 Codex 基线模型声明 `code_mode_only`，原目录继承导致客户端发送私有
`custom exec`，而 Router 当前只接通 function 工具。这些诊断在上游调用前失败，
不能记作模型质量失败。

目录适配保留宿主指令，明确声明已接通的 function 能力。零调用测量显示完整请求的
保守输入计数为 346654，包含宿主工具目录；它不是提供方 token 用量。
据此冻结有限验收输入上界 524288，不删减宿主内容。实际派发边界硬限制八次调用、
每次输出 2048、总等待五分钟，最终七次调用完成修复。

旧 `codex-probe-04` 在预算预留后停止，留下 0.713722 CNY 参考待核对预留，实际
提供方调用为零；原记录保留，不能计为消费。新版探测在预留前测量并停止，
`codex-probe-05` 没有创建调用预留，也没有上游调用。

### 输出预测与等待信息

节点可报告自己的 `expected_output_tokens`，严格检查整数与预测容量。Direct 与 DAG
最终交付使用相同预测，不把中间节点输出相加到 Direct，也不以预测值截断实际输出。
双项真实规划的两个独立修复节点各预测 2000，最终交付与 Direct 均预测 1500。
候选 DAG 参考估值约 0.247804 CNY，Direct 约 0.124002 CNY；这是预测，DAG 没有执行。

DSH 轨迹分别记录正文首段和首个工具请求，隐藏推理及用量回执不当成首字。
金额单位只来自当次冻结模型或账本，保留旧调用显式单位，不重算历史金额。
复验前三个执行轮只有工具请求，正文首字为空；首个工具请求分别为 3801、3538、
2825 毫秒。最终执行正文首字 3192 毫秒，审核正文首字 9473 毫秒；这些模型时间
不能代替用户等待工具及审核的端到端时间。

## 费用、冻结范围与失败保留

二十六次实际 LLM 调用参考估值合计约 **0.88335973603 CNY**，其中包含失败路线；
全部通过原 Ark 订阅路线，新增按量 LLM 现金为零。三次 Jev 新增现金合计约
**0.000740052214 CNY**，单独记账。没有用参考估值冒充新增现金支出。

初始预检计入历史现金保护额 4.56869696 CNY，并额外保护一元未合并的历史 Jev
费用；包含本批最坏调用路径后共保护 19.58869696 CNY，在既有累计 100 CNY
授权内。修复新批次继续沿用累计额度，不重新获得一百元，也不修改用户日常预算。
所有真实付费运行用量已确认，HTTP 自动重试为零。

DSH 的十次执行／五分钟为操作者停止界线，原宿主工具配置保留；不能宣称新增了
核心硬限制。Codex 八次调用上限在实际派发边界强制执行。

## 后续边界

本轮补齐真实工具工作流并修复发现的接线缺陷，不能宣称通用质量达标或 DAG 必然省钱。
双项候选图确实有两个无依赖分支，Router 按当前合格质量先验、现金与参考估值选择
Direct，不为了验收强制执行 DAG。此前受控并行证据继续保留。
