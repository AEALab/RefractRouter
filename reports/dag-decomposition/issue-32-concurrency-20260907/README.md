## 验证结果

- `UV_CACHE_DIR=/tmp/refractrouter-uv-cache uv run --offline pytest -q`：
  **218 项测试、5 项子测试通过**。其中包含调用 26 项 TypeScript 契约的测试，
  两个数字不能简单相加。
- `python3 scripts/validate_dsh_plugin_lifecycle.py --packed`：插件 0.7.0 在真实
  DSH `0.1.1-rc.2`、Node `22.22.3`、pnpm `10.15.0` 下通过 tarball 安装、覆盖、
  卸载、重装及启动。使用隔离临时 profile，付费调用 0。
- 冻结协议的完整 `--demo`：90 次整任务运行、84 次独立节点探测、456 次模拟调用；
  每次请求/响应单独归档，六个比较各有 9 个配对，收益判定始终为 null。
  pytest 中另在禁止 socket 的条件下执行完整流程，仅将启动间隔设为 0 以缩短测试；
  本报告压缩包使用未经修改的冻结协议及 100 毫秒间隔。
- 付费 CLI 在协议指纹不符、缺少授权参数或混用模拟参数时，于创建真实客户端前拒绝；
  核心预算不足时零派发；首个不可用响应停止实验并保留未知用量预留。
- 同步事件测试验证失败、取消和截止时间后停止新派发并结算在途成功响应；独立客户端
  超时和进度 ID 不互相覆盖。服务端费用超过单次预留时，即使总账本尚有余额也停止。
- B 的确定性反例：两分支 10/5 毫秒，汇总 1 毫秒；短分支更贵模型缩短为 1 毫秒，
  总调度时间仍为 11 毫秒。纯时延权重下保留较便宜组合，预测成本 3 而非 7。
  此例只验证目标函数，不是实际模型性能测量。
- 串行与并行对照共用 provider 上限和启动间隔，只改变全局并发度；固定方法顺序仍可能
  受到真实服务随时间变化的影响。只有 3 个测试任务，配对区间只提供探索性描述。
