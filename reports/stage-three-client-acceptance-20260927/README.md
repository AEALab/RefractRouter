# Stage 三客户端功能验收

## 范围与结论

本轮只验收 DSH、Codex、Hermes 从标准 Base URL 调用 `refract/stage`、执行宿主自己的
终端工具并续接同一 Router 任务。未运行质量或节省费用的对照实验。

三个已安装客户端均完成模拟上游的两步工具往返，也分别完成一次 Ark Agent Plan
`deepseek-v4-flash` 真实调用路线。真实批次每客户端两次模型调用、一次宿主工具执行、
一个 Router 任务，均无 HTTP 自动重试。Router 未执行工具或建立 DAG。

| 客户端 | 输入 token（两次） | 输出 token（两次） | 实付 AFP | 高效模型选用 | 真实宿主工具 |
|---|---:|---:|---:|---|---|
| DSH | 290＋371 | 62＋7 | 0.03650 | 两次 | 通过 |
| Hermes | 3677＋3768 | 56＋7 | 0.37540 | 两次 | 通过 |
| Codex | 61535＋62714 | 85＋7 | 6.21705 | 两次 | 通过 |
| 合计 | 132355 | 224 | **6.62895** | 六次 | 三次 |

Codex 的输入含大量原生工具定义和宿主指令；三行费用不可当作客户端效率比较。
零调用预检分别冻结了 0.8704、2.5088、26.2656 AFP 的保守上界，
实际账单均在各自上界内。上界按序列化请求字节估计输入，不等于实际 token。
三个客户端的第二次用户可见文字首字等待分别为 1016、741、2638 ms；
单次样本不构成典型时延结论。

## Stage 换模边界

三种原生客户端把工具结果以标准协议文本送回，目前没有附带可信退出状态、权限或
基础设施错误事实。Router 将结果标为 `unclassified`，每轮决策均为 `no-signal`，
因此真实批次都继续使用高效模型。**本轮没有证明原生三客户端在真实工具失败时会换模。**

新增可选的 `metadata.refract_tool_evidence` 版本化合同。Router 只接受与已完成工具调用 ID
和工具名配对的宿主事实，持久保存后才推进 Stage；不从结果正文猜测失败。
无网络确定性测试注入可信重复失败，验证高效→高效→强执行→保持强执行→恢复高效；
也覆盖冒用调用 ID、矛盾事实与证据写入失败时停止派发。该测试证明核心规则和接线合同，
不等于三种原生客户端已经会发送这个扩展。要完成真实动态换模验收，需由接入方提供
可信结构化工具结果，再在真实工具流程中核对升级、保持与恢复。

## Hermes 首批失败与新批次

Hermes 首批沿用用户原有两档推理参数：高效为 `low`，强执行未设置。
Hermes 对未协商到共同档位的虚拟模型显式发送关闭推理，Router 在模型派发前拒绝；
该批为 **0 次模型调用、0 AFP**，原始失败证据保留。

随后建立独立验收配置，让高效与强执行都冻结为 `low`。新批先进行零调用预检，
再完成两次真实调用；该批未选中强执行模型，不能证明其 `low` 档位的实际上游支持。
此配置只用于本次 Hermes 验收，未修改用户的 DSH profile、
provider、凭证或日常预算。不同执行模型保留不同推理档位时，Hermes 的当前原生
`chat_completions` 接法尚未通过接入验收；需要客户端能省略虚拟模型的推理断言，
或显式选择双方支持的相同档位。

## 复现与证据

最终 `uv run pytest -q` 为 **1341 passed、5 subtests passed**；
TypeScript 类型检查和插件构建通过。Router 0.15.2 已安装到现有独立工具环境，
已安装 `model_gateway.py` 与源码 SHA-256 均为
`31130344defe096a0ee8697b1465c0dca49615a6cb8f6721f0cc93f2619d5f72`。
DSH 插件版本仍为 0.27.0，本轮未重装插件或改动用户 profile。

模拟客户端入口为 `experiments/validate_gateway_clients.py --strategy stage`。
真实客户端入口为 `experiments/validate_gateway_static_live.py --strategy stage`；
先不加 `--execute` 保存零调用预检，再用同一输出目录执行冻结批次。
两个入口均限制两次模型调用；真实入口还限制单次输入上界、输出 512 token，
且只允许预检所列的高效模型。此约束用于本次无信号工具续接验收，
不能拿它验证真实强模型接管。

原始模拟、首次失败、预检和成功批次保存在忽略目录
`.refractagent/acceptance/stage-gateway-20260927/`，包含本机客户端记录，
不得公开上传。公开报告只提取模型、用量、费用、决策与结果字段。
真实批次和首次失败均未覆盖或自动重跑。

## 验收后续

下一项是让接入方在其工具执行边界发送上述可信事实，并分别核对升级和恢复；
无需扩大质量对照实验。完成前，Stage 对这三种纯标准 API 接入的日常行为应说明为
“无结构化工具信号时使用高效模型”。
