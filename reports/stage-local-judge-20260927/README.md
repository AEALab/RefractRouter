# Stage 本地 Judge 协作验收

日期：2026-09-27。结论：策略接线与状态机已实现，本地 Laya 判别质量未通过，保留实验状态。
本次没有修改用户 profile、provider、凭证、额度、已安装软件包或默认模式。
后续同批案例问题对照和修正方向见

## 已实现范围

- 新增独立 `stage-decision-v1`，询问进展、高效模型适合程度与关键信息是否缺失。
- Python 负责触发、原始答案校验、保守备援、保持、连续降档确认、证据去重和最终准入。
- 每任务首轮使用高效模型；默认保持两轮、降档需两次新证据确认，最多四个本地判别批次。
- 本地 Judge 复用常驻进程，包含超时、取消、迟到回执隔离、完整 tokenizer 容量检查。
- 仅预留实际选中的执行调用；本地记录不计入 API 调用上限，不产生虚构现金价格。
- v5 独立配置、DSH 设置与逐步轨迹、能力握手，以及独立 HTTP 服务的显式加载参数。
- 模型请求、工具调用与结果仍交由原宿主处理；新策略不执行工具或进行上下文压缩。

## 冻结的真实本地验收

使用 [24 条题集](../../data/stage-judge-cases-v1.json)，四组各六条：正常探索、需要强模型、
可降档、信息不足；覆盖中文、英文和混合语言。执行前固定题集、问法和 0.8 门槛，
没有根据结果调整门槛或追加题目。

权重：`aac6fef/laya-multilingual-mlx`，revision
`f2b4faf51023039425946074e2cf1361d2db11d5`，GPU／float16。
从既有本地目录加载，设置 `HF_HUB_OFFLINE=1` 与 `TRANSFORMERS_OFFLINE=1`。

| 指标 | 结果 |
| --- | --- |
| 真实本地判别 | 24 次、72 个 Choice 问题 |
| 与预期一致 | 6/24，均来自“信息不足”组 |
| 正常探索放行 | 0/6；门槛要求至少 5/6 |
| 需要强模型却判断高效可用 | 0/6 |
| 最终无法确定 | 24/24 |
| 容量回退 | 0；这批短题都通过完整输入检查 |
| 加载与预热 | 约 1395 ms |
| 暖机后含本地输入检查 P50 / P95 | 约 112 / 125 ms |
| 云端 API 调用与费用 | 0 |

原始答案、分数、用量及混淆矩阵保存在 [local-laya.json](local-laya.json)。输入 token
用量包含同一任务的三个问题，不等于单个问题输入长度。本地推论快只能证明延迟适合，
不能证明能区分下一步是否需要强模型。24 条全部不确定会让当前保守策略持续选择强模型，
所以当前 checkpoint＋问法不能默认用于降低成本。

## 功能验证

新增确定性测试覆盖首轮、高效／强模型切换、两轮保持、连续降档、原始答案非法、容量不足、
未知用量、判别故障、超时、取消、迟到结果、重复回执、任务隔离、历史证据去重、权限与
基础设施结果、判别上限、强模型预算不足、压缩调用状态不变，以及标准模型接口工具续接。
选中模型未能派发时仍保存 Judge 答案，避免报告只留下成功选模。

插件严格类型检查、构建与 159 项契约测试通过；包括新旧配置和不兼容核心的零调用阻断。
完整 `uv run pytest`：1357 项通过，耗时 198.79 秒。最终补充“就绪检查崩溃后重复身份
不能绕过停止”的测试后，Stage 专项 17 项全部通过；该补充没有新增付费调用。

## 验收边界与后续

- 这是实验实现与有限质量否决结论，尚未安装到用户正在运行的 DSH。
- 本次没有新增 DSH、Codex、Hermes 的付费真实端到端验收；之前纯规则的验收记录不能
  代替本次协作模式。标准 API 的新分支目前由无网络完整调用测试覆盖。
- 该题集使用短人工轨迹与明确角色能力描述，不证明实际执行模型的任务质量或长历史适用性。
- 只有 Base URL 而没有可信任务身份时，仍受既有工具关联和用户消息边界约束；压缩后的
  完整任务识别未被本改动解决。
- 真实缓存收益预测、完整任务预期成本及延迟排序尚未接入新协作模式。
- 保留旧规则用于现有日常任务。后续应先更换或专门适配能通过有限门槛的本地 Judge，
  再做三客户端真实接线；不对这批题反复降低门槛，不追加大规模付费实验。

## 重现

```sh
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 uv run python experiments/evaluate_stage_judge.py \
  --cases data/stage-judge-cases-v1.json \
  --model-path <已下载且固定版本的本地权重目录> \
  --output <新的结果路径>
```

评估脚本拒绝覆盖结果；任务执行期间不会自动下载权重或改用云端 Judge。
