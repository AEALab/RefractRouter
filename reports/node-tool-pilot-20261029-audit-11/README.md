采购第一轮的按需专家引用覆盖通过，第二轮却未重复：一次性回答通过，
按需专家缺 `b_confirmed_eligible` 要求的 s1。不能仅保留有利于专家的第一轮。
这些差异属于冻结引用口径，不能写成金额或资格条件算错；同一任务的重复也不是独立新任务。
本观察不改变评分、提示或后续执行，第三轮仍按原计划采集。
