## 发现与修正

1. 费用上界不能假设强模型一定比高效模型贵。首轮按高效模型覆盖，后续每轮按两个执行角色中
   较贵者覆盖。
2. 隔离 DSH 模型目录必须声明计划传入的实际推理等级；只在规划模型中写 `reasoningEffort`
   会在底层派发前失败。
3. 未知用量必须停止批次，同时写出完整失败摘要，保留账本中的待核对金额。
4. 日常任务不应让 Agent 读取 `.refractagent` 运行元数据；它会增加无关调用和上下文。
5. 验收题面的引用格式和 Unicode 语义必须明确，避免把规格歧义误报为路由故障。
6. Stage 只能根据运行中的可见证据调整模型。公开测试全部通过而隐藏检查失败时，没有可用于升级的
   轨迹信号；需要更明确的规格、预先存在的测试或 Advisor、Task、Composite 等其他策略补充。

## 验收边界

本轮没有执行 Static 对照或 72 次收益实验，也没有验证主子 Agent 共享预算。当前可以说明：

- Stage 在日常代码和资料任务中的调用、工具续接、历史、费用与结果交付可用；
- 受控重复失败轨迹中的 Flash → 强模型 → Flash 已通过；
- 当前普通任务没有困难证据，因此未发生实际模型切换；
- Stage 的普遍质量、成本和时延收益仍未证明。
