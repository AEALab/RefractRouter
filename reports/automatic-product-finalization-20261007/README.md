## 修复与解释

- 工具要求解析正确识别“不调用工具”；封闭算术使用复杂度门控 v6，避免不必要的判别
  与审核。其他操作、真实工具要求及严格输出合同继续通过原检查。
- 工具次数不限额时，允许比较已知 planner、执行和评审调用；明确标为
  `known-calls-only-unbounded-tool-continuations`，不承诺完整任务成本上界。
- 轨迹列出全部五款配置模型及数据域排除原因。三款可发送当前输入；DeepSeek Pro
  和 Kimi 因现有云端信任配置排除，未擅自放宽权限。
- 选择顺序保留质量资格、新增现金、公开参考费用。模型画像属于先验，不能冒充本批
  已证明的任务成功率。
- 新记录将外部 Jev 现金与 Router 模型费用分别展示，再给出已知合计；未知用量
  不记成零，也不自动释放待核对预留。

独立任务的已知路线预测为直答约 0.701847 CNY、DAG 约 1.400919 CNY，包含规划和
评审预测。两者是同一决策边界的预测，DAG 未派发；工具续接不限额，不能视为完整
任务费用。真实账本与预测分开保存。
