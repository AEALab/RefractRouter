### analysis-02：问卷与客服统计

- **survey_negative = 14**  
  来源：s1  
  依据：s1 明确记录“自愿填写的50份问卷中，14份表示不满意”。  
  限制：该数字仅反映自愿填写者的不满意份数；未记录未填写者情况，也未记录填写者是否联系过客服，因此不能推断全体客户。

- **service_complaints = 20**  
  来源：s2  
  依据：s2 明确记录“同周共有20条投诉工单”。  
  限制：其中4条是同一客户追问，所以“20条工单”不等于“20个客户”；材料也未允许将其他工单视作不同客户。该值只能作为工单条数使用。

- **can_pool = false**  
  来源：s1、s2  
  依据：两来源无法进行身份对应；问卷的14份不满意与20条投诉工单可能重叠，也可能来自不同人群，且工单数不能当客户数。  
  限制：不能将14与20相加，也不能合并成“全体客户不满意率”。问卷为自愿填写且未记录未填写者，抽样存在偏差；客服记录仅是工单条数，不能代表总体。因此不满足合成全体客户不满意率的条件。

### decision-01：打印与配送

- **printer = P**  
  来源：s1  
  依据：需求为“双面彩色100份”；P报价300元且可双面彩色，满足要求。  
  排除Q的原因：Q报价200元但仅黑白，不满足“双面彩色”的硬性条件。

- **delivery = D**  
  来源：s2  
  依据：要求“须周五前送达”；D报价80元、周四送达，满足时限。  
  排除E的原因：E报价40元但周六送达，不满足“周五前送达”的硬性条件。

- **total_cost = 380**  
  来源：s1、s2  
  依据：P 300元 + D 80元 = 380元。  
  限制与权衡：总预算400元，380元未超预算。不能因为Q和E更便宜就选择Q+E，因为该组合既不满足双面彩色，也不满足周五前送达；最终组合必须同时满足全部条件。

### decision-02：带班资格与早晚班分配

- **feasible = true**  
  来源：s1、s2  
  依据：甲、乙均有有效培训记录，且时间可用条件可以覆盖早晚两班；丙培训过期，不具备带班资格。因此存在符合全部条件的安排。

- **morning = 甲**  
  来源：s1、s2  
  依据：甲培训有效且只能早班，满足早班08:00–12:00；乙只能晚班，不能安排早班；丙培训过期，不能安排。

- **evening = 乙**  
  来源：s1、s2  
  依据：乙培训有效且只能晚班，满足晚班16:00–20:00；甲只能早班，不安排晚班；丙虽两班均有空，但培训过期，不满足“必须持有有效培训记录”的要求，故不安排。

限制：每人最多一班已满足，甲早班、乙晚班；培训过期人员丙未被安排；资格条件、可用时间限制和班次人数限制均予以保留。
