## 当前能说明什么

- 三条路线的金额与资格字段都正确；本组完整检查差异在引用。
- 按需专家与 DAG 都用了三个模型请求。成本差异不是少调了模型，而是累计输入和输出的组合不同。
- 按需专家的累计输入更多、累计输出更少；总费用低于 DAG，但仍高于一次性回答。
- 主循环保留历史可能减少重新生成的工作，但本实验还改变了角色提示和上下文投影，不能单独归因于交接损失。
