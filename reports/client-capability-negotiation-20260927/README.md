## 首次阻断与输入成本

首批以 65536 输入上界预检；实际请求带 141 个工具定义，派发前因预算不足被阻断：
**0 次调用、0 AFP**。旧批次保留，未覆盖或自动重跑。

随后实际客户端零调用探测得到保守输入计数 **255789**。当前上界按序列化字节数估算，
不是已消耗 token。新批次冻结输入上界 262144、输出上限 512、最多两次调用，
费用上界 **26.2656 AFP**，独立测试预算 27 AFP；用户日常设置未修改。

本轮费用主要来自宿主输入。Router 不会擅自删减工具或系统指令来压低成本。
若后续优化工具暴露或提示大小，应由客户端配置控制并单独验证功能完整性。
此前 DSH 小样本与本轮 Codex 的上下文规模不同，不能直接比较路由性能。

## 范围与复现

- 支持的集成方法见 `docs/independent-model-router.md` 的 Codex 本机目录章节。
- 本机目录包含宿主提示，只在忽略目录保存；公开报告仅包含计费字段、汇总和预检摘要。
- 原始失败、探测及成功批次保留在 `.refractagent/acceptance/client-negotiation-20260927/`。
- 首次目录解析发现 `apply_patch_tool_type` 不接受 `function`；按实际可选字段设置空值，
  使用客户端已有 function 工具路线。失败试验没有付费调用。
- 真实路线仅 Static；没有证明 Stage、Task、Escalation 在 Codex 的全部行为已验收。
- 媒体、托管 web search、custom tools、私有 reasoning 历史、增量 response ID 尚未接通。
- 没有替换用户默认 provider、策略、预算或 profile；没有启动长期运行的生产网关。
