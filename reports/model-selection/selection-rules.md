# 三指标单模型选模规则

## C：先检查已有数据

依据 2026-09-07 v0.3 契约修复后的冻结单模型记录：同一任务 `report_001` 重复
3 次、3 个候选、9 份独立最终评审。旧协议的实验不合并进本次候选统计。

| 单模型 | 平均质量 ± 总体标准差 | 平均生产成本 AFP | 关键路径 p50 / p95 秒 |
|---|---:|---:|---:|
| Flash | 90.333 ± 7.760 | 0.66526667 | 49.213 / 76.655 |
| M3 | 88.667 ± 2.867 | 5.12316667 | 50.941 / 53.963 |
| Pro | 84.333 ± 1.700 | 9.16153333 | 73.099 / 89.691 |

Flash 的平均质量和成本更好；M3 的尾部时延更低。Pro 被另两者支配。
以平均质量至少 88、平均生产成本至多 6 AFP 为例：p95 上限 80 秒选择 Flash，
上限 60 秒选择 M3，上限 50 秒无可行模型。质量底线提高到 90 且时延仍限 60 秒，
也无可行模型。这里的数值是用于比较的场景，不是已经确定的生产要求。

三项指标必须来自同一批完整、成功且独立评审的任务与重复轮次。
缺运行、失败、缺评审或非有限数值的候选不参与选择，并报告原因；不通过删掉失败轮次
改善候选均值。成本只含整条路线的生产成本，不含历史探针和评审费用。
p95 使用样本线性插值，与现有 benchmark 一致，选择时不提前舍入。

## A：约束式，首选规则

配置必须显式提供：平均质量下限、平均生产成本 AFP 上限、关键路径 p95 毫秒上限。
三项边界均包含等号；满足全部条件后依次按成本升序、质量降序、时延升序、模型 ID
字典序选出一个单模型。没有可行候选时返回 `no-feasible-model`，不自动放宽条件。

成本约束是历史平均每次运行的预算，不是每次调用或未来运行的硬性计费上限。
质量均值不是每次输出的质量保证。上线仍需要执行时的预算保护和独立验证。

## B：加权式，补充比较规则

先在完整合格的原始单模型候选池上固定三个 min/max，再进行约束过滤。
质量效用为 `(q - q_min) / (q_max - q_min)`；成本和时延效用为
`(x_max - x) / (x_max - x_min)`。某指标全部相同，其效用固定为 1，不影响排名。
不删除受支配模型后重新归一化。报告保存归一化边界与各模型分项效用。

显式提供三个非负、有限且总和为正的权重；内部除以权重总和。
加权总分最高者胜出，同分依次按成本、质量、时延、模型 ID 决胜。
B 可以单独使用，也可以在 A 的硬约束内排序；硬约束不能被加权分数补偿。
示例权重（质量、成本、时延）为 `(0.50, 0.25, 0.25)`，同时展示质量优先、
成本优先和时延优先的敏感性，不将示例权重当成用户已确定的偏好。
候选池改变可能改变归一化与排名，因此边界、候选池和权重必须随结果保存。

## 报告与适用边界

- `quality_baseline` 永远是完整候选中平均质量最高的固定单模型，独立于 A/B 约束。
  保留原有按每轮最终评分取最优的 `task-oracle`，两者含义不同。
- `selected_model` 是 A 或 B 在明确配置下选择的单模型；选模 API 不调用模型。
- 本次报告是样本内离线选择分析，不是跨任务泛化验证。3 次同任务重复的 p95 很不稳定，
  DAG 关键路径也不等于用户等待的端到端响应时间。
- 单节点评分或重放拼接得到的混合路线只可作为预测；新组合必须实际执行整条 DAG 并
  独立评审。历史实际执行的混合路线仅支持其原始任务、输入及轮次，不进入单模型候选池。
- 原有付费 runner、冻结 oracle 规则与历史证据保持原样；新增独立离线入口与可调用选择函数。
