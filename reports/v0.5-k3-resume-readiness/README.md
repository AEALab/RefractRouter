## 评分口径差异

K3 输出含有“一、执行摘要”等编号标题。冻结的章节评分要求标题完整精确相等，
因此该节点的 `score_cap` 为 0，并记录 `missing-sections`；原有生成硬契约将章节覆盖
作为评分项，所以状态仍为 `ok`。另一套任务级确定性评分按文字包含关系得到 90 分。
这解释了原始记录中节点 0 分与任务 90 分并存的现象，两者都不是独立质量评审分。

恢复采用首次生成时相同的硬契约，同时保存完整评分检查结果；本轮没有改写报告、
放宽原有硬契约或调整评分。后续盲评需要实际检查内容；精确标题匹配的改进应在
独立版本中验证，避免在同一对照实验中改变评判口径。
